## 🎯 优化 1：AI 对话界面

### 问题
- 界面冗余信息过多
- 不符合现代对话应用的简洁风格

### 优化内容

#### ✅ 简化了输入区域
- **移除**："继续这次思考" 标签
- **简化按钮文字**："选择文档作为来源" → "文档"
- **简化 placeholder**："继续追问…" → "继续提问..."
- **调整默认高度**：3行 → 1行（自动扩展）

#### ✅ 优化消息样式
- **用户消息**：改为右侧气泡样式
  - 圆角：`18px 18px 4px 18px`
  - 背景：`var(--ui-color-fill-regular)`
  - 最大宽度：75%，右对齐
- **AI 消息**：移除边框，更轻量
  - 无边框、无背景
  - 只保留内容区域

#### ✅ 视觉优化
- 头部图标：16px → 20px
- 消息文字：14px → 15px
- 消息标签：12px → 13px，加粗
- 头部边距：18px → 14px
- 分隔线：`--ui-color-line-regular` → `--ui-color-line-light`

## 🎯 优化 2：顶栏布局

### 问题
- **模型选择下拉框**占据顶栏空间
- 遮挡文档标签栏
- 多个 API Key 无法快速切换

### 优化内容

#### ✅ 移除顶栏模型选择器
```html
<!-- 原来的位置 -->
<div class="app-active-model" id="active-model-control" hidden>
  <label for="active-model">当前模型</label>
  <select id="active-model">...</select>
</div>

<!-- 优化后：移除，腾出空间给文档标签 -->
<div class="app-topbar__spacer"></div>
```

#### ✅ 在菜单中新增模型管理区域
```html
<div class="fmt-menu__section">
  <div class="fmt-menu__section-title">模型与服务</div>
  
  <!-- 当前模型选择 -->
  <div class="fmt-menu__model-select">
    <label for="menu-active-model">当前模型</label>
    <select id="menu-active-model">
      <option>Claude 3.5 Sonnet</option>
      <option>GPT-4</option>
      <option>GPT-3.5 Turbo</option>
    </select>
  </div>
  
  <!-- API 提供商切换 -->
  <div class="fmt-menu__model-select">
    <label for="menu-api-provider">API 提供商</label>
    <select id="menu-api-provider">
      <option value="cc-switch">CC Switch · Codex（默认）</option>
      <option value="claude-api">Claude API Key</option>
      <option value="openai-api">OpenAI API Key</option>
      <option value="custom">自定义服务</option>
    </select>
  </div>
</div>
```

#### ✅ 新增样式
- `.fmt-menu__section`：区块容器
- `.fmt-menu__section-title`：区块标题（11px，大写，灰色）
- `.fmt-menu__model-select`：模型选择项容器
- `.fmt-menu__separator`：分隔线

#### ✅ 菜单宽度调整
- 原宽度：190px
- 新宽度：260px（容纳更长的选项文字）

## 💡 设计理念

### 1. **不遮挡核心内容**
- 文档标签栏是高频使用区域
- 模型选择是配置类操作，低频
- 移入菜单可以减少视觉干扰

### 2. **统一配置入口**
- 所有配置项集中在菜单中
- 模型、API Key、设置都在一个地方
- 降低认知负担

### 3. **支持多服务切换**
- 本地可能同时启动多个 API Key
- 快速在 Claude / OpenAI / 自定义服务间切换
- 不需要每次都进入模型配置页面

## 📊 对比效果

### 优化前
```
┌─────────────────────────────────────────────────┐
│ 观译 | 文档标签1 | 文档标签2 | [当前模型▼] ... │
└─────────────────────────────────────────────────┘
```
❌ 模型选择器占据右侧空间  
❌ 文档标签被压缩  
❌ 无法切换 API 提供商

### 优化后
```
┌─────────────────────────────────────────────────┐
│ 观译 | 文档标签1 | 文档标签2 | 文档标签3 | ...  │
└─────────────────────────────────────────────────┘
                                              ┌────┐
                                              │ ...│
                                              └────┘
                                              ┌─────────────┐
                                              │ 模型与服务   │
                                              │ 当前模型 ▼  │
                                              │ API 提供商▼ │
                                              ├─────────────┤
                                              │ 设置        │
                                              │ 模型配置    │
                                              └─────────────┘
```
✅ 文档标签栏完整可见  
✅ 模型和 API 切换在菜单中  
✅ 配置项统一管理
