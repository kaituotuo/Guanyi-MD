# PDF 翻译功能图标

- 版本：v0.2；日期：2026-11-15。
- [图标预览](图标预览.html)；[回到交互原型](../PDF翻译交互原型.html)。
- 延续观绎 MD 现有墨色主体、朱砂语义和圆端描边；图标是原创 SVG 路径，不依赖字体和外部库。

## 功能与符号

| 文件 | Symbol ID | 名称 | 图形语义 |
|---|---|---|---|
| [selection-translate.svg](selection-translate.svg) | `gicon-selection-translate` | 划词翻译 | 选区角标界定局部范围，A 与「文」构成语言转换。 |
| [document-translate.svg](document-translate.svg) | `gicon-document-translate` | 全文翻译 | 折角纸张界定整份文档，右下「文」强调译文输出。 |
| [save-translated-pdf.svg](save-translated-pdf.svg) | `gicon-save-translated-pdf` | 保存译文 PDF | 折角文档和正文代表新的译文文件，向下箭头落入托盘表示另存输出。 |
| [view-original.svg](view-original.svg) | `gicon-view-original` | 原文视图 | 单页内容和左侧锚线强调原文阅读。 |
| [view-compare.svg](view-compare.svg) | `gicon-view-compare` | 双栏对照 | 等宽双栏与中央分隔直观表示原文、译文并排阅读。 |
| [view-translation.svg](view-translation.svg) | `gicon-view-translation` | 译文视图 | 单页轮廓配「文」字，保留与全文翻译一致的译文标记。 |

保存图标采用“新文档 + 落入托盘的箭头”，按钮文案明确为“保存译文 PDF”。文档身份、语言和新文件路径在保存界面中展示，不把全部信息挤进 16px 图形。图标不用软盘，避免与当前原文件保存混淆。

## 规格

- 坐标：`viewBox="0 0 16 16"`；轮廓大部分位于 1.75–14.25 之间，保留像素边缘安全空间。
- 描边：1.5px、圆端、圆连接；缩放到 20/24/32px 时等比缩放。
- 常规尺寸：工具栏 16px，较大操作入口 20/24px，预览板放大到 32px 辅助检查。
- 点击区域至少 32×32px；有文字的按钮建议高度 34–36px，图文间隔 6–8px。
- 标准亮色：主体 `#2a2520`，语义朱砂 `#bd391b`；暗色：主体 `#f4f1ed`，语义朱砂 `#ff896e`。
- 朱砂用于语言字形、译文段落和保存箭头等功能部分，不使用装饰圆点。

## 使用方式

建议把 `sprite.svg` 中的 `<symbol>` 插入应用现有 SVG sprite。Symbol 无独立颜色，继承调用位置的 `color` 和 `--gicon-accent`。保留以下样式，避免被应用的全局 `svg { stroke: currentColor }` 覆盖。

```html
<button class="save-translation-button" type="button">
  <svg class="gicon" viewBox="0 0 16 16" aria-hidden="true">
    <use href="#gicon-save-translated-pdf"></use>
  </svg>
  保存译文 PDF
</button>
```

```css
.gicon { width: 16px; height: 16px; --gicon-accent: #bd391b; }
.gicon__ink, .gicon__accent {
  fill: none;
  stroke-width: 1.5;
  stroke-linecap: round;
  stroke-linejoin: round;
}
.gicon__ink { stroke: currentColor; }
.gicon__accent { stroke: var(--gicon-accent, #bd391b); }
[data-theme="dark"] .gicon { --gicon-accent: #ff896e; }
.primary .gicon, .disabled .gicon { --gicon-accent: currentColor; }
```

独立 SVG 文件提供 `<title>` 与 `role="img"`，用于素材查看。作为产品按钮内装饰时应使用 `aria-hidden="true"`，以按钮文字作为可访问名称。仅图标按钮必须提供完整 `aria-label` 和悬停文字。

`<img src="…svg">` 作为外部图片时不能继承父元素 CSS 变量；产品内建议内联路径或 `<use>`，以保持暗色和主按钮白色的一致性。SVG 文件的 `color` 为独立预览默认墨色，可在内联使用时移除或覆盖。

## 状态

| 状态 | 图标处理 | 交互与文案 |
|---|---|---|
| 常态 | 墨色主体 + 朱砂语义 | 保留功能名 |
| 悬停 | 图形不抖动，背景轻微加深 | 保持点击区域 |
| 选中 | 原形不变，按钮底色或文字强调 | `aria-pressed="true"`，不可只靠图标颜色 |
| 主操作 | 主体和语义统一为白色 | 避免朱砂在朱砂背景上消失 |
| 禁用 | 主体和语义统一为可读灰色 | 按钮禁用，说明“全文翻译完成后可保存” |
| 处理中 | 原图位置留槽，显示进度或微型加载符 | 保存期间不能重复启动，不改变按钮宽度 |
| 焦点 | 清晰外部焦点环 | 图标本身不接受独立焦点 |
| 错误 | 保持功能图标，可另配错误文字 | 不能只用红色表示失败 |

保存按钮仅在所选全文译文完整可用后启用；当前工具栏目标语言和已完成任务语言不同时，保存界面必须显示实际导出的任务语言。
