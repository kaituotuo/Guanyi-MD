V1.2 设计原则补充：母题 · 留白 · 节奏
① 声波是品牌签名母题——Talko 是语音产品，声波应贯穿加载态 / 空状态 / 头像 / 社区封面，成为可被记住的独占视觉，而不只是回放组件里的一排灰条。
② 留白即情绪——金句、空状态、结束页要敢留白、敢放大，让关键的一句话「被郑重对待」。
③ 节奏要有起伏——不要整页都是「白卡 + 柔投影」。适度引入暖色 full-bleed 区块、编辑化（杂志感）的社区排版，用已定义却闲置的 --grad-card / --grad-voice 打破单调。

金句 / 引言（情绪高地）
金句是产品的情绪触点（详情页、Talk 结束页、被引用的话）。要靠大字号 + 充足留白 + 悬挂引号把它抬起来，而不是塞在小卡片里。留白本身就是「被郑重对待」的信号。
真正的答案，往往在你沉默的那一刻浮现。 — 知微 · 关于跳槽时机的那次 Talk
尺度：hero 金句 28–30px / 行高 1.7；卡片内金句 18px / 行高 1.7。引号用 ::before 悬挂，不占正文行首。
字重 · 层级靠「对比」而非「统一 600」
字重仍限 400 / 500 / 600（禁 700+），但不要全站压在 600——那样层级发闷。高级感来自对比：大字号衬线反而用「轻」（若字库支持 300/400）显优雅，正文 400，只有关键信息才 600。让轻重拉开。

卡片等高规则
同一网格内的卡片必须视觉等高，不因内容长短导致高低不齐。
约束项
约束项实现方式
照片区域固定高度（如 Talker 卡片 280px），不允许弹性伸缩
金句 / 引言min-height 固定两行高度 + -webkit-line-clamp:2 截断
标签行min-height 固定一行高度
正文区flex-shrink:0，不被压缩
网格容器grid 默认 align-items:stretch（同行卡片等高）
反例
❌ 照片用 flex:1 弹性高度 → 小屏卡片缩小
❌ 金句不限行数 → 一行和两行卡片高度不同
❌ 正文区不加 flex-shrink:0 → 被 flex 布局压缩
