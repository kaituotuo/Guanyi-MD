## 1. 结果与设计依据

读者打开外文 PDF 后，能够边读边查选中的词句，也能够主动启动全文翻译，在原文与译文之间保持位置联系；全文完成后可将译文另存为新的 PDF。

### 用户已明确的需求

1. 大型复杂功能先设计方案和原型，再进入开发。
2. 本次为 PDF 新增全文翻译和划词翻译。
3. 用户勾选“划词翻译”后，选中 PDF 中的文字即自动翻译，无需再次点击翻译按钮。
4. 翻译目标跟随软件设定的目标语言，默认中文。
5. 译文以 tip 文本框浮动显示在选区附近。
6. 用户可按 Esc 关闭浮动文本框。
7. 全文翻译完成后，支持将翻译文档保存为新的 PDF。
8. 为翻译、保存及阅读视图设计清晰一致的功能图标；工具栏功能使用图标表示，保留悬停/焦点提示与可访问名称。
9. 移除主页左侧侧栏切换按钮及文档阅读区重复标题行，沿用顶部主页与文档页签导航。

## 任务内翻译工具栏（v0.7）

参考用户提供的 WPS 全文翻译截图，PDF 阅读器顶部采用一条面向当前任务的翻译工具栏。它把翻译设置、阅读视图与导出放在同一条可扫描的层级中；它是 PDF 阅读器的一部分，不建立独立的“全文翻译工作台”模式。

### 桌面端层级（同一 PDF 阅读器内）

从左到右保持以下顺序：

1. **阅读工具与当前文档**：当前 PDF 名称只在顶部文档页签显示；阅读与翻译入口使用纯图标，已有目录、查找、批注、智能研读与批注 PDF 另存保持各自语义。
2. **语言方向**：源语言选择（默认“自动识别”）→ 目标语言选择（默认“简体中文”）。源语言与目标语言是翻译配置，不改变界面语言。
3. **划词翻译**：保留独立开关。开启后，选中 PDF 文本在稳定 300ms 后自动请求并在选区附近显示浮动译文卡片。
4. **全文与视图**：`全文翻译` 为启动入口；`原文 / 对照 / 译文` 为三段式视图，使用 `aria-pressed` 表达当前视图。未完成全文任务时，对照与译文视图保持禁用并说明原因。
5. **历史与更多**：历史按钮展示当前会话的翻译历史原型入口；菜单收纳复制译文、清除缓存等次级动作。两者不抢占“保存译文 PDF”的主操作层级。
6. **阅读控制**：缩小、当前比例（如 100% / 自动缩放）、放大；缩放不改变翻译任务状态，调整后重新计算浮动卡片锚点。
7. **保存主操作**：最右侧固定显示保存译文 PDF 图标按钮，以 `title`、`aria-label` 和悬停/焦点提示提供完整名称。全文翻译未完成、存在失败页或未支持页时保持禁用；“全文翻译完成后可保存”“请先重试失败页”等原因不作为常驻工具栏文案，仅通过 `aria-describedby`、悬停提示或键盘聚焦按需披露。全部校验完成后直接启用并打开保存预览。

桌面端在宽度足够时保持单行；控件之间用分隔线和留白分组，不把所有按钮做成同等强调。主操作使用朱砂色，辅助操作使用表面色和边线。图标使用 16px viewBox 的墨色主线与少量朱砂语义线，功能按钮不常驻文字，使用 `title`、`aria-label` 与悬停/焦点提示提供名称；语言、页码和缩放比例属于当前值，保留可见文字。

### 任务状态与阅读视图

翻译任务和阅读视图是两组独立状态：任务状态包括未开始、翻译中、已暂停、部分失败、已完成和已取消；视图状态包括原文、对照和译文。视图切换不启动、暂停或取消任务，任务状态变化也不强迫用户离开当前阅读位置。

- 用户确认启动全文翻译后，阅读器自动切到“对照”视图，让已完成页面与原文同时可见；这是一次有目的的初始切换，不创建新模式。
- 用户点击“原文”即可回到原文视图，全文任务继续在后台按既定状态运行；需要时可再次点击“对照”或“译文”查看结果。
- “取消”只用于停止当前正在进行中的全文任务。任务未开始、已暂停、部分失败或已完成时不显示可误解为取消任务的动作；取消保留已完成结果，不清空缓存，也不强制改变当前视图。
- “暂停/继续”只改变任务调度；“原文/对照/译文”只改变阅读投影。两者反馈分别放在任务状态条和视图切换控件中。
- 切换语言、页签或视图时避免不必要的模式切换；保留当前页、缩放与用户主动选择的视图。

### 窄屏行为

工具栏始终保持单行。宽屏与窄屏采用同一套纯图标功能按钮，图形尺寸与点击区域保持稳定；窄屏在工具栏容器内横向滚动，不拆成多行或压缩图标。保存译文 PDF 图标按钮位于滚动内容末端；历史和菜单仍需键盘可达。对照视图在窄屏改为“原文 / 译文”切换，不强行保留两列；正文区域不产生文档级横向溢出。

### 基本交互原则

- **任务与视图分离**：任务状态由状态条表达，原文/对照/译文只控制阅读投影；避免把阅读视图误解为独立翻译模式。
- **状态可见**：翻译中、暂停、部分失败和完成状态由阅读状态条持续表达；保存按钮仅用可用/禁用状态表达当前能否导出。
- **就近反馈**：进度与失败原因放在阅读状态条，导出错误放在保存预览内；不让工具栏被动态长文案推动或挤压。
- **渐进披露**：禁用保存的具体原因只在 `aria-describedby`、悬停或键盘聚焦时出现；完成后直接启用按钮，不保留“完成后可保存”提示。
- **工具栏稳定性**：工具栏始终单行，控件保持稳定尺寸；窄屏只在工具栏内部横向滚动，阅读正文不跟随产生文档级横向溢出。
- **无障碍**：按钮、选择框和视图切换保持可键盘到达；纯图标控件提供 `title`、`aria-label` 与悬停/焦点提示，状态由禁用属性、`aria-pressed`、`aria-expanded` 或开关语义表达，不能只靠颜色。

### 工具栏验收项

| 检查 | 通过条件 |
|---|---|
| 语言 | 源语言默认自动识别，目标语言默认简体中文；切换后卡片与新任务使用新设置；已启动全文任务保留语言快照 |
| 划词 | 关闭时选区不请求；开启后卡片定位在选区附近，Esc 可关闭且不会旧请求回弹 |
| 全文与视图 | 全文入口可启动确认；启动后默认进入对照，点击原文可返回且任务继续；原文/对照/译文状态互斥且可读；任务完成前保存保持禁用 |
| 历史与菜单 | 点击显示原型提示或轻量面板，不遮挡正文，不改变当前翻译任务 |
| 缩放 | 缩小/比例/放大控件可达，缩放后正文和浮层仍在视窗边界内 |

## 3. 范围与非目标

### 首发范围

- 复用 1.0.45 本地 PDF 只读阅读视图及页码跳转、缩放、文本选择，不重复开发已有阅读入口。
- 全局目标语言设置、PDF 划词翻译开关、非模态译文卡片。
- 主动启动的全文分块翻译、逐页结果、暂停/继续、取消、失败重试与本地结果恢复。
- 原文与译文按页、段落锚点关联；独立显示翻译进度和失败状态。
- 全文完成后将当前任务译文另存为可选择、可搜索文字的新 PDF；保留必要图形和公式。
- 划词、全文、保存以及三种阅读视图的原创 SVG 功能图标。
- 明暗主题、键盘选区、Esc 和基本屏幕阅读器访问。

### 本轮不承诺

- PDF 原文编辑、把译文写回或覆盖原文件。
- OCR、扫描件识别、手写识别、密码破解或绕过复制限制。
- 与原 PDF 像素一致的译文排版及原版式还原；首发译文 PDF 采用文字重排。
- 公式推导、表格结构修复、保证学术/法律/医疗等专业译文正确性。
- 在线文档上传管理、跨设备翻译缓存同步、后台云端翻译服务。

## 4. PDF 阅读与入口

### 阅读基础

建议采用离线随包的 PDF.js，分开维护页面渲染层与可选择文本层；仅渲染当前页及邻近页，避免长文档全部驻留。

- 本地打开、拖入及系统“打开方式”进入统一文档页签，保留 PDF 图标和完整文件名。
- PDF 文档类型与 Markdown/TXT 分离，不走文本解码、Markdown 保存或富文本编辑路径。
- 工具区展示页码、缩放、目标语言、划词翻译、全文翻译、“保存译文 PDF”及阅读模式。
- PDF 原文只读；现有 Markdown 格式工具、保存回写等操作在 PDF 页签中不出现。
- 切换页签保留每份 PDF 的当前页与缩放；移除列表不删除磁盘文件。
- 文件类型、签名、大小和解析错误在打开阶段处理；容量/页数上限由实测确定后公布。
- 提取文本时保存页码、文本项坐标、阅读顺序及块标识，供选择和译文定位共用。

### 目标语言

设置页新增“翻译目标语言”，默认“简体中文”。PDF 工具栏显示当前生效语言，可快捷调整同一全局偏好。

- 界面语言控制按钮文案；翻译目标语言控制译文内容，两者互不隐式覆盖。
- 首批语言列表建议简体中文、繁体中文、英语、日语、韩语；模型能力不足时明确失败。
- 原文默认自动识别；不要求用户先选择源语言。
- 识别为目标语言时展示“所选内容已是简体中文”等提示，不反向翻译。
- 短词、专名和混合语言可能无法可靠识别，允许模型按上下文直译，避免武断跳过。
- 切换目标语言关闭旧划词卡片并使其请求失效；已有全文任务保留其启动时语言并清晰标注。
- 启动新目标语言全文任务时需显式确认；已完成的其他语言结果仍可切换查看。

## 5. 划词翻译交互契约

### 触发条件

1. 划词翻译已开启，当前活动页签为 PDF，选区完全位于原文文本层。
2. 鼠标抬起、触控选择结束或键盘选择停止后，选区连续稳定 300ms。
3. 按原 PDF 阅读顺序归一化换行、连字符及空白；保留原始选区用于定位与核对。
4. 仅对非空文字发起请求；空白、纯标点不弹卡片，不请求模型。
5. 超过建议上限时显示局部提示，不静默截断翻译。
6. 模型未配置时卡片显示“配置模型后即可翻译”，提供现有模型管理入口；保留选区。
7. 浏览器原生复制、键盘扩选仍可使用，不为自动翻译阻止默认选择行为。

卡片、译文栏、工具栏、输入框和其他页签中的选择均不触发划词翻译。选择卡片译文用于复制时，不关闭卡片、不产生递归请求。

### 非模态卡片

卡片形式接近 tip，但包含可选择的文本和操作按钮，语义应为有标题的非模态区域，而不是不可交互的 ARIA tooltip。

| 状态 | 展示与可操作行为 |
|---|---|
| 关闭 | 原文正常选取与复制，无自动请求 |
| 等待稳定 | 不遮挡拖选；300ms 内更新选区则重新计时 |
| 加载 | 显示语言方向和“正在翻译…”；可关闭；不抢焦点 |
| 成功 | 显示译文、目标语言、复制、关闭；较长译文在卡片内滚动 |
| 缓存命中 | 立即展示，标注无需额外请求的本地结果；不重复发送 |
| 已为目标语言 | 明确说明，无空白卡片或无意义往返翻译 |
| 失败 | 给出可读原因、重试和关闭；保持原文选区 |
| 选区超限 | 提示缩小选区或使用全文翻译，不发送不完整片段 |
| 无可选文本 | 阅读区说明此页需 OCR，不伪造选区或译文 |

加载和成功使用稳定外框，避免译文出现时遮住选区或突然跳动。内容以纯文本安全渲染，模型输出不得作为可信 HTML 执行。

### 位置与焦点

- 以选区末行可见矩形为锚点，默认向下间隔 8px；不足时翻到上方，再在横向边界内修正。
- 不遮住锚定选区，卡片与阅读视窗边缘至少保留 12px。
- 建议宽 360px，窄屏为可用宽度减 24px；高度不超过视窗可用高度的 45%，正文内部滚动。
- 滚动或缩放时重新计算可见锚点；锚点离开阅读视窗则关闭卡片，不悬留旧位置。
- 切页、切页签、进入新模式、关闭划词开关、目标语言变化时关闭卡片并废弃请求。
- 展示卡片不夺取 PDF 焦点；通过键盘可进入其复制/重试/关闭按钮，成功状态用 polite live region 宣告。
- 从卡片按钮关闭后把焦点交回原文阅读容器；用 Esc 从原文关闭不额外移动焦点或滚动。
- 点击卡片内保持卡片；点击阅读空白关闭，重新选择其他文字则直接更新为新请求。

### Esc 与请求失效

关闭顺序统一为“当前活动模态 → 划词翻译卡片 → 已有阅读抽屉”等最上层界面，每次 Esc 只关闭一层并停止向下传递。

- Esc、关闭按钮及开关关闭立即隐藏卡片，同时取消该请求并递增 selection/request revision。
- 网络取消可能存在延迟；即使响应稍后返回，也须校验文档、选区、语言和 revision，失效结果不得重新打开卡片。
- 关闭后保留原文选区，记录 dismissed selection key；原选区未发生变化时不能自动再次弹出。
- 只有用户清空后重选或建立不同的选区，才解除关闭抑制；复制和焦点切换不解除。
- 新选区遵循 latest-wins：取消旧选区请求，只允许当前选区结果更新卡片。

## 6. 全文翻译与双栏阅读

### 启动与分块

点击“全文翻译”进入任务确认：显示文件名、可提取页数、目标语言、当前模型及发送范围；按钮为“开始翻译”。无法提前精确计算费用时不编造金额或耗时。

- 全文指全部可提取正文页；空白页、图像页和提取失败页分别记录，不混算为翻译成功。原图保留并在结果中说明后可计为已处理，仍有未处理或失败内容时不开放保存。
- 按页建立任务，页内按可读段落与模型上下文预算分块；每块保留稳定 ID 和页码。
- 优先当前阅读页，再顺序处理其余页面，尽早让用户读到结果；进度使用完成页/总页与当前状态。
- 每块返回后校验 ID、完整性、目标语言和终止原因；输出截断或缺块属于失败，不标记整页已完成。
- 已完成的块逐步显示；尚未完成区域展示占位和状态，不把原文误当作译文。

### 任务控制

| 状态/操作 | 约定 |
|---|---|
| 翻译中 | 可继续读原文，显示进度、暂停、取消 |
| 暂停 | 停止调度并取消在途请求，保留已经校验的结果；按钮为“继续翻译” |
| 继续 | 重新读取当前可用连接，从未完成块继续，保存新批次模型信息 |
| 取消 | 停止调度并废弃在途响应；保留已完成结果，后续可从未完成部分重新开始 |
| 部分失败 | 已成功内容可读；显示失败页数和“重试失败部分”，不重跑成功块 |
| 连接失效/限流 | 提示检查配置或稍后重试；有限重试后暂停队列，避免持续请求 |
| 完成 | 所有正文块校验通过、必要原图等已处理且无失败/遗漏后，显示完成并启用“保存译文 PDF”；未支持内容须另列，不能显示虚假 100% |
| 应用退出 | 下次恢复为“已暂停”，用户继续后才恢复网络请求 |

切换页签不取消已主动启动的全文任务，其他页签仅显示轻量进度；关闭 PDF 页签时暂停任务并保留结果。启动后默认进入对照视图，点击原文只回退视图，不停止任务；取消仅停止进行中的任务。Esc 不隐式取消全文翻译，仅关闭当前最上层浮层；取消动作只在任务进行中提供。

### 对照模式与定位

- “仅原文”保留最大阅读宽度；“双栏对照”左侧 PDF，右侧是按页排版的可读译文。
- 原 PDF 图形、图像与页码保持不变；译文采用自然段排版，不承诺复制其字体、换行和精确几何布局。
- 页码同步为基础保障，段落锚点为更精细保障；点击译文段落可定位并轻量标记对应原文块。
- 同步滚动以当前页/段落 ID 为依据，不用两边总滚动高度比例；程序性滚动设防回流锁。
- 无可靠段落对应关系时退回页级同步并显示提示；不制造精确对齐假象。
- 模式切换保留页码/段落位置，不重新生成译文；任务状态与视图状态分离，进入原文模式时全文任务仍按用户启动的状态运行。
- 狭窄窗口改为“原文 / 译文”切换，两个视图共享页锚点；不压成两栏难以阅读。
- 双栏中划词仅作用于左侧原文；右侧中文可以正常选择、复制，不再次调用模型。

## 7. 保存译文 PDF 与功能图标

### 保存入口与任务归属

“保存译文 PDF”以原创 SVG 图标按钮常驻工具栏，完整名称放在 `title`、`aria-label` 和悬停/焦点提示中。未完成时禁用，但不在按钮旁常驻“全文翻译完成后可保存”说明；通过 `aria-describedby`、悬停或键盘聚焦按需给出“全文翻译完成后可保存”“请先重试失败页”等原因。全文完成且校验通过后直接启用；进度和失败状态放在阅读状态条，不能只靠颜色提示。

- 仅对当前正在查看、已经完整校验的全文任务开放保存；无失败块、未处理页或遗漏的表格/图形。
- 输出语言取当前译文任务的语言快照；工具栏切换到新的划词目标语言时，不改变已经显示的旧任务输出语言。
- 点击后展示保存预览：译文语言、内容类型、预计输出页数及保留原图说明。若重新排版后页数与原文不同，分别标注原文页数和输出页数。
- 默认名为 `原文件名-目标语言-译文.pdf`，例如 `Walking and everyday movement-简体中文-译文.pdf`；系统另存对话框允许改名、选择目录，并固定或自动补全 `.pdf` 扩展名。
- 另存目标必须是独立新文件，不允许写回原 PDF 路径；与其他文件重名时交由系统确认替换或改名。取消系统对话框返回阅读，不误报保存成功。
- 首版只保存译文及必要原图/公式；不自动附加整份双语原文，不把内存缓存或屏幕截图直接冒充成品 PDF。

### 输出与恢复

| 状态 | 行为 |
|---|---|
| 准备 | 绑定任务、语言、文件指纹和译文版本的不可变快照，检查内容及字体可用性 |
| 生成中 | 展示“正在生成 PDF…”和进度，可取消；禁止重复保存请求，不影响阅读或翻译缓存 |
| 系统另存 | 用户选择文件名与目录；取消不改变译文任务的完成状态 |
| 写入中 | 先写临时文件，成功校验后提交为目标新文件；不得留下被误认成完整文件的半成品 |
| 成功 | 明确显示实际文件名与保存位置，提供“打开 PDF”“在文件夹中显示” |
| 失败 | 给出生成、字体、磁盘空间或权限原因，保留已完成译文，允许重试或换位置，不重新翻译 |
| 取消 | 停止生成/写入并清理本次临时产物，保留原文、译文和此前已保存文件 |

- 采用 A4 可读版式、自然分页；长段落跨页，标题避免孤行，表格不裁断内容，图形按可用宽度缩放。无法可靠重排的表格/公式可保留原图并明确说明。
- 文字保持可选择、可复制与可搜索，嵌入所需的许可字体；覆盖简繁中文、日文等目标语言字符，不使用整页截图替代文本。
- 保留标题层级、数字、单位、引用编号、公式及必要图形；标记“原文第 N 页”对应关系。图像页若原样保留，显式标记“原图保留，图中文字未翻译”，不能静默漏页或冒充翻译完成。
- 保存前检查页数、缺块、空白异常、溢出与字体；生成后验证 PDF 可解析且所有块都有输出去向。页数变化不等于缺页，必须按源块映射核对。
- 导出完全本地，不重新请求模型。翻译任务与导出任务分别管理；导出中的快照不因切换语言、清缓存或开启新翻译而改变，必要内容保持引用直至导出结束。
- 浏览器版用下载方式交付并显示“已发起下载”；只有桌面文件写入完成才能报告具体保存路径及提供系统“在文件夹中显示”。

### 图标规范

图标资源与尺寸对比见[功能图标预览](../2%23原型/图标/图标预览.html)。图形采用 16px 网格、墨色主线、朱砂语义笔画、圆端细线，支持 16/20/24px；亮暗主题使用现有令牌，朱砂实色主按钮上的全部笔画统一为白色。

| 功能 | 图形语义 | 交互与可访问性 |
|---|---|---|
| 划词翻译 | 文字选区与语言转换 | 纯图标开关有可访问名称、悬停/焦点提示与明确开关状态 |
| 全文翻译 | 整页文档与语言转换 | 纯图标按钮；处理中保持稳定尺寸并更新可访问名称与进度反馈 |
| 保存译文 PDF | 折角文档与另存箭头/托盘 | 图标按钮具备“保存译文 PDF”名称及提示，禁用时按需说明原因 |
| 原文 / 对照 / 译文 | 原始文档、双栏、译文文档 | 三项按钮分别有名称与选中状态，不能只靠红色区分 |

SVG 设为 `aria-hidden`，纯图标控件名称来自 `aria-label`，同时提供 `title` 与悬停/焦点提示；狭窄窗口允许工具栏横向滚动，图标与点击区域不缩小。普通、悬停、按下、禁用、处理中及暗色状态均保证辨识与对比度。

## 8. 文档边界与异常

| 情形 | 行为 |
|---|---|
| 纯扫描页 / 无文本层 | 页面仍可读，说明“此页暂无法提取文字，需 OCR”；全文任务记录未支持页 |
| 加密 PDF | 支持正常输入密码解锁后阅读；不持久保存密码；无密码则停止打开，不绕过限制 |
| 复制/提取受限 | 尊重文档权限，说明不能翻译受限文字，保留允许的阅读能力 |
| 双栏 / 多栏论文 | 结合坐标恢复阅读顺序，提供原文核对；低置信页提示顺序可能有误 |
| 跨行断词 | 仅合并确定的行尾断词，不删除有语义的连字符；始终保留原始片段 |
| 公式 / 代码 / 引用编号 | 原样保留稳定标记，不让模型改写数值、变量、公式或补造引用 |
| 表格 | 首版按提取文本翻译并提示结构可能变化；不能可靠提取时保留原图和未支持说明 |
| 图中文字 | 无文本层不自动识别；图注有文本层则可翻译 |
| 损坏 / 超大文件 | 给出具体失败原因，原文件不变；允许移除、重选或稍后重试 |
| 原文件外部修改 | 重新计算指纹，旧结果标为旧版本，用户确认重新读取后再生成新结果 |

## 9. 模型链路、并发与数据

### 复用链路

PDF 字节 → 本地 PDF.js → 页/段文本与坐标 → 选区或任务分块 → 翻译调度器 → 现有模型请求桥 → 校验 → 本地结果缓存 → 卡片/译文栏。

- 使用现有模型管理与 CC Switch，不新增第二套 API Key 或服务地址配置。
- 划词每个新请求读取当前连接；全文任务启动固定模型、协议、目标语言与提示词版本。
- 全文暂停后继续若模型发生变化，提示新部分使用当前模型，已完成内容保留原模型标识。
- 划词优先于全文，建议最多 2 个在途请求、全文最多 1 个；有划词需求时暂停发起新的全文块。
- 每类任务独立 AbortController 和 token；关闭划词卡片不得取消全文，全文取消不得破坏划词结果。
- 超时、429 和临时网络错误最多有限重试；认证错误、参数错误不持续自动重试。
- 以文档指纹、任务 ID、块 ID、目标语言和 generation revision 校验返回，防止错文档、错语言或旧响应覆盖。

### 数据最小化与翻译约束

- 划词默认只发送选中文本和目标语言；需要额外上下文时限定邻近段落，不能静默发送全文。
- 全文仅发送当前块及有限前后文，不上传 PDF 二进制、原文件路径、批注、目录列表或其他文档。
- 开启划词时说明“选中文字会发送到当前模型服务”；全文确认页说明按块发送当前文档文本。
- 文档内容作为待翻译数据，不能执行其中的提示、工具调用或系统指令；严格区分系统翻译规则与原文。
- 模型只输出译文，保持专名、数字、单位、公式与引用关系；不把摘要、解释或补写当作翻译。
- 本地日志只记任务状态、错误码和耗时，不记录正文、API Key、完整绝对路径或密码。

## 10. 持久化与失效

- PDF 原始字节/磁盘文件为原文真源；提取文本、译文和坐标均为可重建派生数据。
- 全局偏好：目标语言、划词开关、最近阅读模式；新文档继承，首次默认为关闭划词。
- 文档阅读状态：文件身份、当前页、缩放与模式；不把浮层、临时选区及活动请求恢复到下次启动。
- 全文任务：保存文件指纹、总页数、语言、模型信息、提示词/提取版本、块状态和已校验译文。
- 划词缓存建议仅保留当前会话、最多 100 项；key 包含文件指纹、页/选区文本、目标语言、模型与提示词版本。
- 全文缓存持久保存在应用数据中；不自动创建原文件旁的翻译文件，首发提供“清除此文档译文”。用户主动保存的新 PDF 独立于缓存，清缓存不得删除已保存文件。
- 原文件指纹、文本提取版本或目标语言变化时不混用缓存；模型/提示词变更不覆盖旧结果，可显式重新翻译。
- 缓存不存在或损坏时保留 PDF 阅读，提示重新翻译；不可用空结果冒充已完成。

## 12. 验收矩阵

| 编号 | 场景 | 通过标准 |

| S04 | 选区附近卡片 | 正常、靠底、靠右、长译文均不越界、不遮选区 |

## 13. 待评审选项

1. 译文 PDF 的版式方向：保存新 PDF 已确定；建议首发 A4 文字重排，保留源页码对应与必要原图，高保真版式还原单独立项。
2. 首发是否包含扫描件 OCR？建议先完成可提取文本 PDF，后续基于真实扫描件评估本地/云端方案。
3. 划词开关是否跨重启保留？建议保留用户偏好，首次开启说明发送范围，始终在工具栏显示启用状态。
4. 跨页超长选区是否翻译？建议遵循同一 4,000 字符上限，超过时用全文翻译，不静默截断。
5. 全文缓存是否长期保留？建议按文档本地保留并提供清除入口；容量和清理策略经样本实测后定。

以上建议不阻断本轮原型评审，尚未转化为产品代码或正式安装包。
