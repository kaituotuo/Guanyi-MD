# 观绎 MD

**Guanyi‑MD**

> 俯仰观物，绎述我心。

仰而观天文，俯而察地理。

人之有思，始于观：怀好奇以望世间，持敏锐而察万物，一切皆由“我”而起。

观而后绎，便是抽理纷乱的思绪，打捞转瞬的灵感，将内心的体察与向往，铺陈为文，向外发送。

观绎 MD，不以工具束缚人，而为人承载思想。

愿于此编辑器之中，观见万象，绎述本心。

一款以本心为源的 Markdown 编辑器，观览万象，抽绎所思。浏览器版可以直接双击运行，桌面版进一步提供完全本地的文档语义搜索。

## 名字由来

“观”出自《周易・系辞上》：“仰以观于天文，俯以察于地理。”

以己身为主体，怀好奇之心，敏锐观照天地万象，不随外物偏移，守“以我为主”之本。

“绎”出自《论语・子罕》：“巽与之言，能无说乎？绎之为贵。”

绎，抽丝理绪，推阐本心。将观察所得内化沉淀，再把所思所想梳理、发送、表达于文字。

产品内核是：向外观万物，向内绎本心。永远好奇，永远敏锐，心怀美好，以书写者为中心，把内在思考交付笔墨。

## 运行

直接打开 `index.html` 即可使用编辑、预览、本地文件、批注和导出能力。

桌面开发模式：

```bash
npm install
npm run desktop
```

如需使用本机模型转发：

```bash
node tools/dev-server.mjs --port 9929
```

然后访问 `http://127.0.0.1:9929/`。

## 桌面安装包

正式安装包位于 `release/current/`，历史版本位于 `release/archive/`，解包验收内容位于 `release/build/`：

- macOS Apple Silicon（M1 / M2 / M3 / M4 等）：`release/current/Guanyi-MD-1.0.34-mac-arm64.dmg`
- Windows Intel / AMD 64 位：`release/current/Guanyi-MD-Setup-1.0.34-win-x64.exe`

macOS 版使用 ad-hoc 本地签名，Windows 版未使用商业代码签名证书；两者均未发布到应用商店。在未加入 Apple Developer 签名与公证、Windows Authenticode 签名前，首次安装时系统可能显示开发者信任提示。

本地重新构建：

```bash
npm install
npm run build:mac
npm run build:win
```

构建脚本会将 Electron 与 Electron Builder 的下载缓存统一保存在项目内的 `.cache/`，避免重复下载，也不依赖 macOS / Windows 不同的 shell 环境变量写法。

发布新的补丁版本时使用 `npm run release:patch`。该命令会先将版本号递增一位（例如 `1.0.1` → `1.0.2`），再构建 macOS 与 Windows 安装包；普通 `build:*` 命令只重建当前版本，不修改版本号。

## 核心能力

- 源码、预览、分栏三种工作视图
- Markdown 常用格式、表格、任务列表与快捷键；列表回车自动续写，空列表项回车退出
- 本地选择、URL、拖拽和剪贴板图片插入；等高画廊每行支持 1–6 张，可拖动图片跨行插入或调整顺序，目录文档使用 `assets/<文档名>/` 相对路径
- 本地文档打开、拖拽导入、保存、重命名和目录扫描；目录默认扫描 5 层，支持 `.md`、`.markdown` 和 `.txt`，单份文档不超过 20 MB，自动识别 UTF-8、UTF-16 与 GBK/GB18030 文本
- 单一搜索入口自动匹配最近文档、文件名、目录名和 Markdown/TXT 正文，并在桌面版自动补充语义相关结果；支持在“当前文档列表”（编辑器内已添加的全部文档）与“当前打开文档”之间切换范围，搜索模式仍由系统统一融合，支持结果高亮、键盘选择和 `Ctrl/Cmd+Shift+F` 快捷入口
- 桌面版本地搜索内置 `bge-small-zh-v1.5` INT8 ONNX 模型与 Meilisearch `v1.53.1`；自动融合文件名、目录、正文关键词和语义相关性，支持句子、段落、多段、小节、章节五级召回并精确定位证据句；中文错字查询会保留稳定片段和否定词，多路结果经加权 RRF、证据排序与段落去重统一输出；本地服务失败会自动重试并记录诊断，确认索引损坏时先保留副本再受控重建
- 原文回答自动区分作品内直答与跨情境类答，可联合多部作品并逐字核验出处；答案支持收藏、复制引用和一键接续写入当前文档
- “问作品”复用同一本地高召回索引，通过受控问题规划扩展人物、情节、动机、处境与表达检索；大模型只接收有限编号证据并只能选择原文编号，规划、语义服务或回答模型异常时自动降级为可定位的本地原文
- macOS 桌面版的大模型调用经受限主进程通道执行，支持请求取消、超时与体积上限；瞬时错误有限重试，模型不可用时仍保留本地原文检索结果
- 文档大纲、阅读进度、批注与伴随文件
- 用户主动触发的 AI 辅助阅读
- 统一导出入口，可选 Markdown、PDF 和 PNG 长图
- 亮色与暗色主题
- 桌面与移动端响应式布局

## 项目结构

```text
.
├── index.html              # 可独立运行的单文件应用
├── desktop/               # Electron 桌面入口与系统集成
├── build-resources/       # macOS / Windows 应用图标
├── css/app.css             # 观绎 MD 产品主题与界面样式
├── js/app.js               # 编辑器与文件工作流
├── js/docs-data.js         # 内置文档
├── docs/                   # 内置文档与产品研发说明
├── models/                 # 桌面版本地语义模型
├── runtime/meilisearch/   # 固定版本的 macOS / Windows 本地搜索引擎
├── tools/                  # 本地服务与单文件同步工具
├── vendor/                 # 离线第三方依赖及许可证
└── release/                # current 正式包、archive 历史包、build 解包验收目录
```

修改拆分源码后执行：

```bash
node tools/sync-single-file.mjs
```

该命令会把 `css/app.css`、`js/docs-data.js` 和 `js/app.js` 同步到 `index.html`。

搜索界面、技术架构、验收标准和后续研发阶段见 [`docs/搜索原型与研发计划.md`](docs/搜索原型与研发计划.md)。

## 设计

界面遵循观绎 MD 设计系统：暖白工作区、墨色内容、朱砂主操作、克制的阴影和紧凑的工具布局。品牌标识以“方印 + 竹简 + 朱砂编绳”构成：方印亦是观照世界的窗口，竹简承载所观，中央的 Markdown 井号连接古典书写与现代编辑，抽出的绳尾则将思绪编次成文。全部功能图标来自项目内置的 16 像素原创 SVG 图标库：厚墨线建立清晰视重，朱砂色直接构成箭镞、字形笔画、文件结构与天象等动作或对象语义，不使用无含义的品牌色装饰点。所有组件令牌和图标语义均由项目自身维护，不依赖外 UI 框架。

可复用的品牌图形文件位于 `assets/guanyi-md-mark.svg`。

## 数据与隐私

- 文档与偏好默认保存在当前浏览器。
- 本地文件和目录仅在用户主动选择后读取。
- 桌面版把编辑状态、已添加目录的绝对路径和文档索引备份在 `~/Library/Application Support/guanyi-md/state/editor-state-v1.json`；安装新版本不会删除该目录，因此当前文档、目录配置、视图偏好和未发布编辑内容会继续保留。
- 桌面版新打开的单份文档和新添加的目录都使用系统原生绝对路径访问，不依赖会随浏览器配置变化的 `FileSystemFileHandle` / `FileSystemDirectoryHandle` 授权。旧版本仅保存了浏览器句柄的项目，升级后可能需要手动重新选择单份文档或“重新连接目录”一次；迁移成功后会记录绝对路径，后续应用启动和普通升级不会再次要求应用内授权。应用内已保存的文档内容不会因此丢失，移除应用列表中的目录或文档也不会删除磁盘上的原文件。
- 当前 macOS 包采用 ad-hoc 签名。若目录位于“桌面”“文稿”等受 macOS 隐私保护的位置，系统级 Files & Folders 提示可能在新构建后再次出现；这是 macOS 对新签名的安全确认，不代表观绎 MD 清除了文档或目录配置。使用稳定的 Apple Developer ID 签名与公证后，系统级升级体验才可稳定继承。
- 搜索范围仅包含用户已添加或已选择的文档与目录，不会扫描整台电脑。
- 桌面语义搜索使用随应用安装的本地模型与 Meilisearch sidecar；服务仅绑定本机回环地址并关闭遥测，文档分片、查询、向量和索引不经过互联网，也不会上传到模型服务。
- 模型请求只在用户主动生成辅助阅读时发送当前文档。
- API Key 不会写入 Markdown、批注伴随文件或导出内容。
