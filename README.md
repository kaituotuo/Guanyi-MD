# 观绎 MD

**Guanyi‑MD**

> 俯仰观物，绎述我心。

仰而观天文，俯而察地理。

人之有思，始于观：怀好奇以望世间，持敏锐而察万物，一切皆由“我”而起。

观而后绎，便是抽理纷乱的思绪，打捞转瞬的灵感，将内心的体察与向往，铺陈为文，向外发送。

观绎 MD，不以工具束缚人，而为人承载思想。

愿于此编辑器之中，观见万象，绎述本心。

一款以本心为源的 Markdown 编辑器，观览万象，抽绎所思。浏览器版可以直接双击运行，桌面版进一步提供完全本地的文档语义搜索。

## 名字由来

“观”出自《周易・系辞上》：“仰以观于天文，俯以察于地理。”

以己身为主体，怀好奇之心，敏锐观照天地万象，不随外物偏移，守“以我为主”之本。

“绎”出自《论语・子罕》：“巽与之言，能无说乎？绎之为贵。”

绎，抽丝理绪，推阐本心。将观察所得内化沉淀，再把所思所想梳理、发送、表达于文字。

产品内核是：向外观万物，向内绎本心。永远好奇，永远敏锐，心怀美好，以书写者为中心，把内在思考交付笔墨。

## 运行

直接打开 `index.html` 即可使用编辑、预览、本地文件、批注和导出能力。

桌面开发模式：

```bash
npm install
npm run desktop
```

如需使用本机模型转发：

```bash
node tools/dev-server.mjs --port 9929
```

然后访问 `http://127.0.0.1:9929/`。

## 桌面安装包

构建产物位于 `release/`：

- macOS Apple Silicon（M1 / M2 / M3 / M4 等）：`Guanyi-MD-1.0.1-mac-arm64.dmg`
- Windows Intel / AMD 64 位：`Guanyi-MD-Setup-1.0.1-win-x64.exe`

macOS 版使用 ad-hoc 本地签名，Windows 版未使用商业代码签名证书；两者均未发布到应用商店。在未加入 Apple Developer 签名与公证、Windows Authenticode 签名前，首次安装时系统可能显示开发者信任提示。

本地重新构建：

```bash
npm install
npm run build:mac
npm run build:win
```

发布新的补丁版本时使用 `npm run release:patch`。该命令会先将版本号递增一位（例如 `1.0.1` → `1.0.2`），再构建 macOS 与 Windows 安装包；普通 `build:*` 命令只重建当前版本，不修改版本号。

## 核心能力

- 源码、预览、分栏三种工作视图
- Markdown 常用格式、表格、任务列表与快捷键；列表回车自动续写，空列表项回车退出
- 本地选择、URL、拖拽和剪贴板图片插入；等高画廊每行支持 1–6 张，可拖动图片跨行插入或调整顺序，目录文档使用 `assets/<文档名>/` 相对路径
- 本地文档打开、拖拽导入、保存、重命名和目录扫描；目录默认扫描 5 层，支持 `.md`、`.markdown` 和 `.txt`，单份文档不超过 20 MB，自动识别 UTF-8、UTF-16 与 GBK/GB18030 文本
- 单一搜索入口自动匹配最近文档、文件名、目录名和 Markdown/TXT 正文，并在桌面版自动补充语义相关结果；无需选择搜索模式，支持结果高亮、键盘选择和 `Ctrl/Cmd+Shift+F` 快捷入口
- 桌面版本地搜索内置 `bge-small-zh-v1.5` INT8 ONNX 模型，模型推理与向量索引均在本机完成；索引按文档指纹增量更新，模型不可用时仍保留文件名、目录和正文匹配
- 文档大纲、阅读进度、批注与伴随文件
- 用户主动触发的 AI 辅助阅读
- 统一导出入口，可选 Markdown、PDF 和 PNG 长图
- 亮色与暗色主题
- 桌面与移动端响应式布局

## 项目结构

```text
.
├── index.html              # 可独立运行的单文件应用
├── desktop/               # Electron 桌面入口与系统集成
├── build-resources/       # macOS / Windows 应用图标
├── css/app.css             # Talko V1.2 产品主题与界面样式
├── js/app.js               # 编辑器与文件工作流
├── js/docs-data.js         # 内置文档
├── docs/                   # 内置文档与产品研发说明
├── models/                 # 桌面版本地语义模型
├── tools/                  # 本地服务与单文件同步工具
├── vendor/                 # 离线第三方依赖及许可证
└── release/                # DMG、EXE 与解包验收目录
```

修改拆分源码后执行：

```bash
node tools/sync-single-file.mjs
```

该命令会把 `css/app.css`、`js/docs-data.js` 和 `js/app.js` 同步到 `index.html`。

搜索界面、技术架构、验收标准和后续研发阶段见 [`docs/搜索原型与研发计划.md`](docs/搜索原型与研发计划.md)。

## 设计

界面遵循 Talko 设计系统 V1.2：暖白工作区、墨色内容、琥珀主操作、克制的阴影和紧凑的工具布局。品牌标识以“方印 + 竹简 + 朱砂编绳”构成：方印亦是观照世界的窗口，竹简承载所观，中央的 Markdown 井号连接古典书写与现代编辑，抽出的绳尾则将思绪编次成文。全部功能图标来自项目内置的 16 像素原创 SVG 图标库：厚墨线建立清晰视重，朱砂色直接构成箭镞、字形笔画、文件结构与天象等动作或对象语义，不使用无含义的品牌色装饰点。所有组件令牌和图标语义均由项目自身维护，不依赖外 UI 框架。

可复用的品牌图形文件位于 `assets/guanyi-md-mark.svg`。

## 数据与隐私

- 文档与偏好默认保存在当前浏览器。
- 本地文件和目录仅在用户主动选择后读取。
- 搜索范围仅包含用户已添加或已选择的文档与目录，不会扫描整台电脑。
- 桌面语义搜索使用随应用安装的本地模型；文档分片、向量和索引不经过网络，也不会上传到模型服务。
- 模型请求只在用户主动生成辅助阅读时发送当前文档。
- API Key 不会写入 Markdown、批注伴随文件或导出内容。
