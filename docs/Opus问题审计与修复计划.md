# Opus 问题审计与修复记录

## 审计结论

| 编号 | 报告判断 | 当前证据 | 结论 |
| --- | --- | --- | --- |
| 1 | `index.html` 曾被旧安装包覆盖 | 单文件同步检查可恢复，源码与产物存在漂移风险 | 已恢复，纳入发布闸门 |
| 2 | loose task list 的复选框与文字错位 | `ensureTaskContent` 已把 `<p>` 内复选框归一化为 `li` 的两列结构 | 已修复，保留回归测试 |
| 3 | 代码块、缩进代码、引用块导致任务索引错位 | 原实现用裸正则 + DOM 下标，最小案例可复现 | 已修复为围栏/缩进/引用感知扫描 |

| 5 | 嵌套/多段内容可能产生空白续行 | 原实现给每个换行直接追加固定缩进 | 已修复为逐行清理与重建续行 |
| 6 | 预览态 Tab/Shift+Tab 不完整 | 原实现未拦截预览态 Tab | 已补充列表项缩进、反缩进和边界保护 |

## 验收范围

- 代码块、四空格缩进代码、引用、嵌套任务与正文任务混排。
- 无序、有序、任务列表交替，预览 Enter、Backspace、Tab、Shift+Tab。
- 预览、源码、分栏三种视图的结构保持与撤销连续性。
- 单文件同步、编辑器矩阵和完整回归矩阵。

## 发布闸门

源码变更后先执行 `node tools/sync-single-file.mjs`，再运行聚焦测试与 `npm run test:regression:all`。只有全部通过后才升级版本并构建 macOS arm64 安装包。
