# 观译阅读器 1.0.47 安装与验收

验收日期 2026-11-25。目标平台为 Apple Silicon Mac。Markdown/TXT 编辑及阅读、PDF、EPUB 的工具栏采用与 Web 相同的整排居中。

## 覆盖安装

1. 保存内容并按 `⌘Q` 退出旧版。
2. 打开 [1.0.47 DMG](../release/current/Guanyi-Reader-1.0.47-mac-arm64.dmg)，将「观译阅读器」拖入镜像内的「应用程序」，系统提示时选择「替换」。
3. 从「应用程序」启动，核对关于界面的版本为 1.0.47。推出安装镜像。

应用路径为 `/Applications/观译阅读器.app`，应用标识为 `com.guanyi.md`，资料目录为 `~/Library/Application Support/guanyi-md`。替换安装沿用该资料目录。
