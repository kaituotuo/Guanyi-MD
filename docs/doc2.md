# Markdown 功能演示

这份文档用于体验编辑器支持的常用 Markdown 格式。

## 基础格式

普通文字可以包含 **加粗**、*斜体*、~~删除线~~ 和 `行内代码`。

> 引用适合突出结论、提示或需要特别关注的内容。
