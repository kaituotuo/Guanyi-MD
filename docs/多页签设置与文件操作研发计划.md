# 多页签、设置与文件操作研发计划

## 产品目标

让观绎 MD 从“一次只处理一份文档”升级为稳定的本地多文档工作台：用户可并行打开文档，明确地保存、另存或移动当前文档，并在一个全局入口中管理外观、编辑、搜索与版本信息。

## 范围

本轮先交付 Web 版可验收实现，不打包 macOS 或 Windows 客户端。不更改现有文档格式、搜索索引或 `.REVIEW.md` 协议。

## 核心行为契约

### 多页签

- 文档列表中点击文档时，打开或激活对应页签，不重复打开同一文档。
- 页签支持切换、关闭、拖动排序和键盘左右移动。
- 关闭页签只关闭工作区，不从文档列表或磁盘删除文件。
- 未保存页签关闭时提供“保存并关闭”、“不保存”和“取消”。
- 每个页签独立保留文档身份、未保存状态、撤销/重做历史、源码选区和滚动位置。
- 页签条在主工作区内，首页签左边缘与侧边栏分割线对齐，不遮挡品牌 slogan。

### 保存分裂按钮

- 主按钮保持“保存当前文档”。
- 下拉菜单固定为：保存、另存为、移动到、打开文件位置。
- `Command/Ctrl+S` 保存，`Shift+Command/Ctrl+S` 另存为。
- 所有命令作用于当前页签文档，不从“最近打开时间”反推对象。

### 另存为

- 保留原文件，在目标目录创建新文件，成功后当前页签切换到新文件。
- 默认复制已有 `.REVIEW.md`，可关闭。
- 观绎托管的 `assets/<文档名>/` 一起复制；文档名变化时同步重写受管图片相对路径。
- 目标目录未在文档列表中时，默认加入文档列表，可关闭。

### 移动到

- 正文、托管图片和 `.REVIEW.md` 作为同一文档事务迁移。
- 成功后保留文档 ID 和页签位置，更新文件名、路径、目录树和搜索索引身份。
- 失败时恢复目标原内容与源文件，提示“移动失败，原位置没有变化”。
- 索引更新失败不回滚已成功的文件迁移，但显示可重试状态。

### 目标与冲突

- 目标来源包括：最近使用目录、已添加目录和“其他文件夹”。
- 同名时可选“保留两份”、“替换”或“取消”。
- 保留两份按“文件名 2.md”递增，批注与资源目录使用相同后缀。
- 文件名未写扩展名时沿用原文档格式，不通过另存或移动隐式转码。

## 状态模型

```js
state.openDocIds = [];
state.currentDocId = null;
state.settings = {
  theme: 'light',
  historyLimit: 50,
  editorFontSize: 15,
  editorLineHeight: 1.75,
  startupView: 'split',
  defaultSearchScope: 'list',
  txtIndent: true,
  txtBlankLines: true
};
```

文档对象继续是正文、路径和保存状态的唯一真相源。页签只保存打开顺序和会话状态，不复制文档内容。

## Web 文件事务

Web 端使用 File System Access API 及现有 IndexedDB 句柄存储。对不支持该 API 的浏览器，明确降级为下载副本，不声称已完成移动或打开系统文件位置。

事务顺序：

1. 验证目标句柄的读写权限、文件名和冲突策略。
   直接打开的 Web 文件若未缓存原文件夹，必须在用户点击“移动”的当次手势中发起原目录授权。
2. 备份将被替换的目标内容。
3. 写入目标正文、资源目录和批注侧车。
4. 读回目标并校验正文。
5. “移动到”在目标校验通过后才移除源端。
6. 任一文件步骤失败时恢复目标备份，源端保持原状。
7. 成功后才提交内存状态、页签身份和最近目录。

## 设置与关于

顶部右侧只保留一个“更多”入口，使用三点图标，不用齿轮代表整个应用。菜单项为设置、检查更新、帮助和关于。

首期设置：

- 外观：明色 / 暗色。
- 编辑：撤销记录 20 / 50 / 100 步，编辑器字号和行距。
- 布局：启动视图与分栏比例。
- 搜索：默认范围为“当前文档列表”或“当前打开文档”。
- 文学阅读：仅 TXT 的段首缩进与空行显示。
- 数据：本地优先说明、文档/图片/索引位置。
- 关于：版本、产品简介、更新和帮助。

## 验收矩阵

| 能力 | 主路径 | 组合/异常路径 |
| --- | --- | --- |
| 多页签 | 打开、切换、关闭、拖动 | 未保存关闭、页签与文档列表对齐、重启恢复 |
| 保存 | 按钮、快捷键 | 切换页签后对象正确、保存失败不误标已保存 |
| 另存为 | 正文、图片、批注 | 不复制批注、同名三策略、另存后再移动 |
| 移动到 | 同文档身份迁移 | 写入/删除中断、回滚、路径连续性 |
| 设置 | 修改、保存、重启恢复 | 明暗主题、320px 窄窗口、焦点返回 |
| 关于 | 版本、帮助、更新入口 | Web 端能力边界文案 |

所有流程要求无未捕获异常和控制台错误。本轮通过 Web 完成功能验收后停止，不进入客户端打包。
