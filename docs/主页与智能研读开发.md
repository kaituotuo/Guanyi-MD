## 交付范围

主页成为常驻且不可关闭的导航页签。冷启动进入主页；从系统或文件选择器打开文档后进入该文档。主页保留已有文档夹，最近文档只按真实 `lastOpenedAt` 降序排列；保存、后台扫描和编辑不更新此时间。主页搜索保留独立输入边界，不加整条背景框或重复的“主页”标题。打开文档后隐藏文档夹，只展示当前文档导航、正文与相关工具。按用户对工具栏的确认，MD/TXT 默认沿用 1.0.40 的编辑方式，完整显示格式、源码/预览/分栏、保存、导出、主题与原智能审阅入口；TXT 不适用的格式项仍禁用。用户主动选择“阅读”才进入只读，新建 Markdown 直接编辑；PDF/EPUB 仍进入各自阅读器。

AI 快捷入口默认自由对话，可主动关联已导入文档。发送前展示来源与处理范围；选定资料的回答仅接受已提供的证据编号。文字与证据在本机提取，模型复用现有配置、桌面 IPC 与请求取消接口。对话可以整理成真正的 Markdown 文档；不把预设原型回答接入正式界面。

PDF 智能研读提供导读、文档对话、学习卡、批注。用户主动准备明确页段，准备完成后生成有原文依据的导读与少量候选学习卡。候选经预览、编辑、确认才入库，自测先隐藏答案。选区与当前页问题冻结发送范围；翻页不改待发送依据。来源定位使用不写入 PDF 的临时覆盖，支持回到阅读位置。笔记与学习卡可以整理成带原文、页码和版本的 Markdown。

## 1.0.44 EPUB 审阅与模型连接（本地体验包已完成）

EPUB 阅读器接入 Markdown 已有的同一智能审阅抽屉，保留“批注 / AI 辅助阅读 / 问作品”三个页签；不在共享侧栏之外再增加 EPUB 研读面板。工具栏入口为纯图标，保留可访问名称、展开状态与焦点；头部 54px，X、遮罩、Esc 关闭、焦点回到入口、未发送草稿和当前页签保留，明暗与窄屏规则同 Markdown。EPUB 章节 iframe 中的 Esc 也遵循共享关闭行为；输入区方向键不误触发翻页。顶部“…”及模型配置仍在侧栏与遮罩之上，并且是唯一常驻配置入口。

“批注”页承载 EPUB 原生高亮、笔记、颜色、CFI、删除及 Markdown 笔记导出。注释仍由原有 EPUB 数据管理，原书字节不变，不迁移或覆盖 Markdown 的 `.REVIEW.md`。每本 EPUB、MD 审阅和 PDF 研读保持独立文档状态；共享的只是界面和交互约定。

AI 辅助阅读使用发送时冻结的当前章节或选中文字，界面说明实际范围，不声称已经阅读整本书。章节范围绑定原始 spine 索引，不能使用过滤后的数组序号；发送的是本地提取的真实原文和临时证据编号，不发送绝对路径或未选章节。只有逐字匹配的引用可展示为原文依据；未知编号、编造引用和模型生成的链接、路径或 CFI 不作为定位来源。本地定位先校验来源哈希与章节，再以精确文本 Range 转 CFI；无法精确匹配时只定位章节并明确说明。问作品复用原有范围和来源校验，证据不足时保留本地原文结果。跨书“定位原文”首次点击会等待目标阅读器就绪，再核验目标文档/来源并定位真实章节，避免把加载期间暂时没有阅读桥误报为来源变化。

关闭审阅、切换文档、回主页或销毁阅读器会取消对应的在途生成。响应的文档 ID、来源版本与请求身份必须仍匹配，晚到结果不能写进另一本文档或恢复已停止的任务。取消保留未发送问题、已有结果与注释；用户在生成期间新输入的下一条问题优先保留，不被已取消请求的旧提交问题覆盖，关闭重开和重载一致；原生注释、AI 结果和问答持久化各自保存，保存失败保留活跃实例与草稿，不显示成功、也不清空数据。

模型配置的裸域地址统一解析到 `/v1/chat/completions`；已有 `/v1`、兼容前缀和完整 `chat/completions` 地址保留原路径语义，模型列表使用相应 `/models`。不把 `/messages` 或 `/responses` 静默改成另一协议。配置连接测试和主页、MD/EPUB 审阅、PDF 研读实际生成共用端点与响应处理。HTML 网页、无效或空 JSON、鉴权、模型不存在、额度、限流、网络与超时均给中文原因和下一步；界面不回显密钥、响应正文或 `Unexpected token '<'` 解析异常。测试连接须实际请求配置服务，不能只凭模型名或字符串判断成功；取消和失败不丢输入或已有结果。

PDF 阅读工具栏与正文之间的第二条灰线来自 PDF.js 隐藏原生工具栏的剩余上下 padding 与 box-shadow。本轮只清除该隐藏壳的 padding、border、shadow；宿主正常分隔线和 PDF 正文 `overflow:auto` 保留，高倍缩放仍可水平滚动，不通过隐藏溢出裁切原文。

## 1.0.43 界面修订与验收（本地体验包已完成）

本轮按用户反馈修复顶栏“…”菜单在智能审阅打开时被遮挡的问题。菜单应在 Markdown 审阅、PDF 研读及覆盖遮罩之上完整显示并可点击，窄屏和明暗主题同样遵守；Esc 关闭、焦点归还与键盘导航保留。层级须包含顶栏父层，不只提高菜单自身层级。

模型配置统一从“顶部 … > 模型配置”进入同一配置弹窗。主页、Markdown 智能审阅、PDF 智能研读均移除独立配置按钮；未配置时保留输入、来源范围、草稿和可读错误，文案引导到顶栏菜单。用户主动生成而缺少模型配置时通过全局菜单引导，不发送原文、不清空本次输入。

PDF 工具栏的“智能研读”入口改为纯图标，与其他阅读工具保持同一视觉尺寸；保留 `title`、`aria-label`、`aria-expanded`、`aria-controls` 和可见焦点。面板内部的导读/对话/学习卡/批注文字页签保留。PDF 研读与 Markdown 审阅统一 54px 侧栏头部和 X 图标关闭；X、遮罩与 Esc 均关闭面板，关闭后焦点回到原触发入口，重新打开不丢笔记草稿、选中页签或已有结果。

Markdown 大纲放到预览页左侧，默认关闭；编辑格式栏提供图标开关，阅读工具栏原开关保留，大纲标题 X 可关闭。布局结构为 `源码 | 分隔器 | [大纲 | 预览]`；大纲与预览属于同一预览容器，不能放在源码或整个工作区左侧。源码模式暂时隐藏大纲，但回到预览/分栏保留开关状态；预览容器足够宽时大纲内联占 220px；预览容器宽度 ≤560px 时改为覆盖式，宽度取 240px 与容器 85% 的较小值，遮罩仅覆盖预览容器，定位标题后自动收起。触发条件取预览容器宽度，不能只按窗口断点判断。

品牌 slogan 恢复并固定为“俯仰观物，译述我心”，只有用户明确授权时才可修改；当前界面、关于和设计规范保持一致。
