## 本轮已完成

- 固定工具栏加入“查找和替换”入口。
- 当前文档查找支持大小写不敏感、匹配计数、上一个/下一个、`Ctrl/Cmd+F`。
- 替换面板支持替换当前和替换全部，空替换内容可用于删除匹配文本。
- 查找结果在源码视图定位选区，在预览视图使用醒目的朱砂色主匹配高亮。
- 替换复用现有 `setCurrentMarkdown` 历史链路，因此可以撤销/恢复，并会触发语义索引更新。

## 图片编辑优化计划

### P0：图片选中态与上下文工具条

为 `.app-image-row` 增加明确的 `aria-selected` / CSS 选中态。单击图片只选中图片，不改变正文光标；工具条锚定图片上方或下方，超出视窗时自动翻转。工具条至少提供：替换图片、删除图片、左/中/右对齐、更多操作。

### P1：替换和删除

替换沿用原图片的行位置、替代文本和图片顺序；删除单张图片后自动合并相邻图片行，空行删除时保留一个可编辑占位段落。两项操作都写入同一历史记录，失败时恢复原 DOM 和 Markdown。

### P1：尺寸与比例

增加图片块宽度预设（原始、半宽、整行）和自定义宽度。自定义宽度写入稳定的 Markdown 扩展属性或应用侧元数据，不把临时 CSS 样式污染正文。拖拽角点必须锁定宽高比，并设置最小/最大宽度。

### P2：拖拽和键盘可达

图片拖拽继续遵守每行最多 6 张；拖拽经过目标行时显示插入位置，超过上限立即显示不可放置反馈。补充键盘选中、删除、左右移动和跨行移动，确保不依赖鼠标。

### P2：一致性验收矩阵

组合验证“图片 + 任务列表 + 回车/退格 + 撤销恢复 + 查找替换 + 导出”。重点检查图片前后光标、图片行数量、Markdown 往返一致性、语义索引失效与重建，以及源码/预览/分栏三种视图的结果一致。

## 暂不实现的内容

本轮不直接引入裁剪画布或复杂图片编辑器。裁剪会改变图片数据和导出链路，需先确定是否保存为新文件、是否允许覆盖原图，再单独设计数据模型和恢复策略。
