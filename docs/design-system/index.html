01

设计原则

以本地阅读、摘录与编辑为中心。通过暖纸色、墨色文字与克制的朱砂橙建立层级。

01 / READ

文稿优先

正文先于工具，预览保持舒适行距与有限阅读宽度，界面结构不压迫内容。

02 / ORIENT

明确当前位置

页签、文档树与视图选择有清楚的选中态；颜色配合位置、标线与文字。

03 / EXPLAIN

说明结果

保存、冲突、检索和审阅状态写出发生了什么；暂时性反馈不承担唯一信息。

AI 对话

读完一篇文章后，怎样整理出有用的笔记？

可以先回答三个问题：

  1. 作者想解决什么？ 用一句话写出核心问题。
  2. 什么证据支撑结论？ 留下原文出处，方便回头核对。
  3. 这对我有什么用？ 写下自己的理解与下一步行动。

先保留你真正想记住的内容，再逐步补充细节。

此样例直接引用 home-workspace.css：用户气泡靠右，助手无外卡片，消息居中，输入框自适应高度，来源“+”与发送/停止在框内。会话侧栏替代对话中的文件树；回主页恢复文件列表。顶部“AI 对话”入口从阅读/编辑返回时恢复原活动消息与草稿。会话“…”和右键菜单可软删除，记录可在全局菜单恢复。历史、来源、复制与整理能力由真实应用提供，样例按钮不发送请求。所有可关闭弹框统一右上角 X 图标，具有 title、可访问名称与键盘焦点；X 沿用取消语义。

适配与反例

原型必须标注所演示的格式、主题与宽度。不要把静态视觉样例当成已上线能力。

桌面与宽屏品牌区与侧栏边界对齐；页签横向滚动。macOS 标题栏为交通灯留出安全区，控件不进入该区域。
≤760px主页文件夹由按钮打开覆盖抽屉；阅读和编辑收起主页文件夹；工具栏横向滚动；分栏上下堆叠；弹窗靠底并保持内容可滚。
预览容器独立于窗口宽度：大纲默认关闭；预览宽 >560px 内联 220px，宽 ≤560px 用 min(240px, 85%) 覆盖且遮罩仅预览区。源码模式暂藏，标题定位后自动收起。
≤360px页签和设置表单继续压缩，保留操作文案、焦点和可触达区域。
明暗主题同时核对纸面、源码、边线、选中态和反馈。主题切换使用同一组语义角色。
无障碍纯图标按钮有可访问名称；键盘焦点可见；当前项、错误与文件类型有文字或形状辅助说明。

推荐与避免

新原型的基本检查
DO / 推荐写明状态和去向

“已保存到本地文档”“磁盘版本已更新”，并给出下一步入口。按文件格式使用对应工具栏。
