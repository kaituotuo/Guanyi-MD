# 文学名著理解与运用功能方案

## 产品定义

在观绎 MD 现有全文匹配、语义检索和原文回答能力之上，增加“文学工作台”：用户输入现实问题、人物问题、主题或写作意图，系统从用户自己的文库中找到可核验原文，再把人物处境、冲突、选择和结果转化为理解框架与写作素材。

这不是让模型模仿名著随意编故事，而是把“原著证据”和“文学运用”组成一个可回查的闭环。

## 核心原则

1. 用户不需要选择搜索模式，系统自动联合关键词、语义、人物关系和情节结构召回。
2. 原文、解释和改写必须分区显示，不能把生成内容冒充原著。
3. 每一条逐字引文都能定位到用户文库中的作品、章节和字符范围。
4. 没有足够原著证据时，应返回相关场景或明确提示证据不足，不强行生成结论。
5. 文学材料用于理解、表达和启发，不替代现实事实调查与专业判断。

## 一、原著证据链

### 用户能做什么

- 问人物事实：“袭人的名字是怎么来的？”
- 问情节因果：“周瑜为什么打黄盖？”
- 问概念出处：“花气袭人知骤暖出现在什么场景？”
- 问人物关系：“赵云为什么愿意追随刘备？”
- 问主题演化：“《红楼梦》中宝玉如何看待功名？”

### 系统返回什么

- 最小命中句；
- 前后段落和章节上下文；
- 作品、章节、文件路径和精确定位；
- 与问题直接相关的关键词高亮；
- “原著明确写明 / 可从情节推断 / 暂无足够证据”的证据等级。

## 二、文学镜像

用户输入现实问题，例如“为什么组织里能力强的人反而会被排挤”。系统将问题拆成：角色、资源、权力关系、冲突、选择、结果，再检索结构相似的文学场景。

结果不只返回一句相似文本，而是一张“文学镜像卡”：

- 现实问题结构；
- 相似文学场景；
- 逐字原文；
- 相似点与不同点；
- 该类比能解释什么、不能证明什么；
- 展开章节、复制引用、收藏、接续写入。

## 三、人物思想实验

在严格区分原著和改写后，用户可以提出：

- “如果王熙凤面对现代公司的预算危机，她会先处理什么？”
- “用曹操、刘备、孙权三个视角分析同一场组织冲突。”
- “让宝玉和贾政分别回应‘稳定工作还是自由创作’。”

回答分三层：

1. **人物依据**：列出原著中支持该人物判断方式的原文；
2. **迁移规则**：说明从原著处境迁移到现实问题的对应关系；
3. **明确改写**：生成内容统一标记“基于原著人物的思想实验”。

## 四、多作品母题对照

用户输入“忠诚”“背叛”“权力”“婚姻”“名利”“成长”“组织兼并”等母题，系统从多部作品中找出正反案例，按同一结构比较：

## 五、用典与引用校验

这是观绎 MD 区别于普通 AI 写作工具的关键能力。

- 检查一句话是否真是原著原文；
- 找到最接近的真实原句；
- 标出省略、改写、人物错置和章节错置；
- 对引用生成统一格式的出处；
- 文档更新后复核引用指纹；
- 对模型生成的仿写显示“非原文”标识。

## 六、从阅读到写作

每一组结果提供四个接续动作：

- **加入素材夹**：保留问题、原文、出处和关系说明；
- **生成提纲**：将人物、冲突、选择、结果转成文章结构；
- **接续写入**：写入当前文档并附带引用来源；
- **保留反例**：同时保存一个不支持当前观点的文学场景，防止单向附会。

## 自动处理流程

1. 识别问题中的事实查询、概念、现实处境或创作意图；
2. 做全文匹配、模糊匹配、语义召回和人物/事件召回；
3. 将句子扩展为段落、场景和章节，恢复人物与因果上下文；
4. 校验引文字符范围和文档指纹；
5. 判断输出类型：直接证据、情节推断、文学类比或思想实验；
6. 生成关系说明和类比边界；
7. 按证据强度排序并呈现操作入口。

## 数据能力

在现有句子、段落、小节、章节索引之上，增加以下结构：

- 人物别名与称谓：刘备 / 玄德 / 皇叔；
- 人物关系：主从、亲属、盟友、敌对、师徒；
- 事件链：前因、触发、行动、直接结果、长期结果；
- 场景要素：地点、资源、身份、权力和限制条件；
- 母题标签：忠诚、背叛、名利、组织、婚姻、成长等；
- 原文与改写标识：`quote`、`inference`、`analogy`、`adaptation`。

所有结构化数据都保留回到原始文本的偏移量和哈希，不能成为脱离原文的第二套事实源。

## 研发顺序

### 第一阶段：证据可信

- 原著事实问答；
- 句子到章节的上下文展开；
- 人物别名识别；
- 原文定位、复制引用和引用校验；
- 原文与改写标签。

### 第二阶段：文学镜像

- 问题结构拆解；
- 场景和因果链召回；
- 相似点、差异点和类比边界；
- 素材收藏和接续写入。

### 第三阶段：思想实验与多作品对照

- 人物立场模拟；
- 多人物、多作品对照；
- 写作提纲和反例；
- 用户可维护的母题与案例库。

## 验收基准

- 引文必须能逐字回到本地文档；
- 人物别名查询能召回同一人物的不同称谓；
- 点击证据能定位到命中句，而不是只打开文档；
- 原文与仿写在视觉和数据字段上都不可混淆；
- 现实问题至少返回相似点和差异点，不能只给“看起来相关”的段落；
- 不支持当前观点的反例可被正常召回；
- 文档改变后，历史引用会提示重新校验。
