- 最新 PDF.js/EPUB.js 及完整本地字体、worker、WASM 等依赖随源码同步，主页、MD/TXT、PDF、EPUB 使用最新共享阅读模块。

- 本轮没有构建、替换或发布安装包；远程公开网站也没有部署。浏览器不能调用原生应用菜单或桌面高召回索引，这些仍是桌面集成能力。
