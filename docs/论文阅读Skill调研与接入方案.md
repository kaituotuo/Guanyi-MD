# 论文阅读 Skill 调研与接入方案

核对日期：2026-11-15；图像接入更新：2026-11-16。本轮研究三个仓库的真实提示词、引用资料、许可和宿主依赖，并核对观译当前 PDF 研读调用。本文件记录研究结论、已接入的 PDF 全文阅读流程及验收边界。

## 结论

以第二个 **freestylefly/paper-reader-skill** 作为默认论文阅读流程，符合当前“快速读懂关键方法、主要结论，再逐步精读和沉淀知识”的目标。它只有 README、SKILL 和 MIT 许可三份文件，核心是可嵌入模型请求的文本指令，无 Python、联网检索或特定 Agent 工具依赖。

“接入”的具体含义是在观译发往当前模型的请求中加载该 Skill 的指令和观译适配约束，并由观译完成原文读取、任务编排、来源定位和结果保存。将文件安装到 Claude/Codex 的 Skills 目录，不能使现有 Web 应用自动获得该能力。

## 第二个具体提供什么

依据固定版本 [SKILL.md](https://github.com/freestylefly/paper-reader-skill/blob/3fb7d74aae85444a61f8a27ddf1f3cb2f0ed2ce2/SKILL.md)：

- 第 20–40 行：三层输出；论文按“问题→方法→实验→结论”组织，另有技术报告、白皮书、商业案例和书籍章节框架。
- 第 42–74 行：卡片包含核心观点、关键证据、应用场景和相关联想；术语首次出现用白话、定义或类比解释。
- 第 103–145 行：完整解读包含背景、核心方法、实验与结果、局限、知识卡片、原文摘录和延伸阅读。
- 第 187–214 行：先判断文档类型，再解读；要求忠实原文、标注不确定性、区分结果与作者推测、适度简化。

它对“研究过程”的要求体现为技术路线和实验设计；并未实现逐段精读界面、PDF 解析、图表识别或引文真实性核验。多论文综述是给模型的任务框架，仍要求宿主把多篇材料实际提供给它。

## 直接接入的适配边界

保留原版 SKILL 及其三层方法，以单独适配层解决观译产品契约，不把内容手抄为另一份难以追溯的提示词。

1. **输入与来源。** 已移除 PDF 研读的 80 块、20 页默认范围与 50 页上限，默认全文；文档对话默认全文，用户仍可主动锁定选区或页段。`js/paper-reader.js` 按原始文字层顺序完整发送所有非空块，重复内容不去重，超长块连续拆段且不截断。超过单批预算时逐批读完、再分层综合全部笔记；只有全部原文块的所有分段成功发送并通过结果校验才标为完成。原生多栏顺序保持并提示核对，不能凭坐标自造段落；页眉和图注不替代研究正文。
2. **文类适配。** 先识别文档与研究类型。系统综述/Meta 分析使用“研究问题→检索→纳入排除→质量/偏倚评价→数据提取→统计合成→主要结果”，覆盖效应量、置信区间、异质性和敏感性分析等实际出现的项目；不强迫生成不存在的实验、数据集或基线。书籍章节沿用其观点、论证、案例、应用框架。
3. **输出适配。** 原版 Markdown 模板转成观译的结构化字段，保留一句话总结、研究背景、核心方法、研究过程、主要结果和作者结论；术语解释随内容出现。学习卡继续先作为候选，由用户确认后保存。输出中的来源编号必须映射本地原文，模型不能生成页码、坐标或 CFI。
4. **事实与解释。** 原文结果、作者解释、辅助类比和模型提出的质疑分别标识。原 Skill 的“我发现的问题”“我能怎么用”“相关联想”属于辅助分析，不自动变成作者结论或经过验证的应用建议。临床或训练应用不把研究层面关联直接转换为个体干预建议。
5. **图表与摘录。** 当前 PDF 研读同时发送全部原生文字和范围内全部页面图像，覆盖嵌入图片、矢量图表、表格和扫描页；每批最多三张，逐批完整阅读后综合。图表要求核对轴、单位、图例、比较条件与不确定性，无法辨认的数字不得补写。图像来源仅绑定真实页面，不伪造逐字引文或精确框选；可查看原图并定位原页。原文摘录仍须逐字匹配本地文字，中文翻译另外标识。模型不支持图像或任一页生成失败时本次研读失败，保留旧结果。
6. **延伸阅读。** 原 Skill 要求推荐相关资料；当前研读没有联网检索验证流程。默认仅使用原文中可核对的参考文献，无法验证时不生成貌似真实的标题、DOI 或链接。后续联网检索作为明确的独立功能。
7. **生命周期。** 任务冻结文档、范围、模型与来源版本；保留取消、进度、失败重试和文档隔离。缓存身份增加 Skill 提交、适配器版本、抽取版本和阅读模式，升级后不误复用旧的通用导读；已有笔记与结果可保留查看。

## 建议的用户阅读路径

1. **核心速读：** 百字内总结，关键方法、主要发现和作者结论；先回答“研究了什么、怎样研究、发现什么”。
2. **完整解读：** 按第二个 Skill 的框架展开研究背景、方法与过程、结果、局限、术语，以及 1–3 张候选卡片。
3. **定点精读：** 从方法步骤、段落、公式或图表进入文档对话，解释原文并可回跳；逐节教学与图表精读可借鉴第三个，完整证据审读可借鉴第一个。

模式、范围和来源独立；缺失提醒集中说明，主体以已有证据支持的研究内容为先。未知结论继续留空，不以完整格式强迫模型补齐原文缺口。

## 实施验收要求

- 长篇论文超过 80 块、50 页时，仍把所有可提取文字按顺序提供给模型，包括末页结论；逐字核对连续输入与覆盖计数，报告读取和综合范围。
- 用真实实证论文、系统综述/Meta 分析与书籍章节分别检查输出，不仅验证模拟 JSON 和页面交互。
- 按原文核对核心方法、主要结果数字及条件；对模型未知来源、伪造摘录、错误置信区间和未看图即下结论进行拦截或明确降级。
- 失败、停止、切文档、切模型、重载与缓存升级保留最新草稿及已有笔记，不采纳迟到结果。
- 回归现有 PDF 原生批注、研读笔记、候选卡片确认、Markdown 导出、深浅主题和窄屏布局。

已将第二个 Skill 的原始规则、固定提交和 MIT 许可随 Web/客户端共用的 `index.html` 分发；未安装到本机 Agent，也未执行第三方脚本。其余两个 Skill 仍为研究资料。本轮未构建或发布安装包；具体校验结果见下方实施记录。

## 页面图像接入记录（2026-11-16）

- **输入完整性：** 全文研读和默认全文提问发送每页真实渲染图及所有原生文字，无片段采样。当前页/指定页段只发送所选范围；选区解释发送选中文字及所在整页图像，并在发送前说明。纯扫描页可由视觉模型阅读，不会因此生成可精确高亮的原生文字层。
- **图像与传输：** 原页白底 JPEG，最长边不超过 2000px、每页不超过 2MiB，每批最多三页，按批渲染并及时释放。客户端、本地 Web 代理与三种协议共用图像转换与取消路径；图文请求上限 12MiB，纯文字限制仍保留。任意渲染或模型能力失败均不静默跳页、删除图片或降级为文字完成。
- **原文结合：** 解读可引用本地页面图像编号，展示“图表依据”、原图预览、定位图表所在页和返回阅读位置。图片仅用于当前请求及本地临时预览，持久化和 Markdown 导出只保存来源身份与页面信息，不保存 base64。文字复制权限同样约束图像发送；独立渲染不更改原 PDF、注释、阅读位置或缩放。
- **浏览器验收：** 七页测试 PDF 包含无原生字幕的彩色矢量图、栅格图、矢量表格及扫描页。请求端实际解码 JPEG 并核对像素与 SHA-256；所有页面、原图预览/定位/返回、真实渲染取消、请求取消、不支持视觉时保留旧结果、重载、导出及 1440/390 明暗布局通过。61 页专项逐字核对 94976 字符并确认全部 61 幅页面图像发送。真实 Bakker PDF 的 30 页、3489 块、118825 字符及全部 30 幅图像逐一通过发送边界核验。上述全篇检查使用模型响应夹具，只验证实际输入与交互，不等同于全篇云模型语义验收。报告位于 `.tmp-test/paper-vision-browser/report.json` 和 `.tmp-test/paper-reader-browser/report.json`。
