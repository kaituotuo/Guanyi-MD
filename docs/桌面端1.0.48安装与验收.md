# 观译阅读器 1.0.48 安装与验收

验收日期 2026-11-25。目标平台为 Apple Silicon Mac。1.0.47 的版本号从 Mac 客户端读取，关于页说明和两个更新动作却共用了写死的 Web 提示。

## 覆盖安装

1. 保存内容并按 `⌘Q` 退出旧版。
2. 打开 [1.0.48 DMG](../release/current/Guanyi-Reader-1.0.48-mac-arm64.dmg)，把「观译阅读器」拖入镜像内的「应用程序」，选择「替换」。
3. 从「应用程序」启动。在顶栏「…」→「关于观译阅读器」核对版本 1.0.48。

应用路径为 `/Applications/观译阅读器.app`，应用标识为 `com.guanyi.md`，资料目录为 `~/Library/Application Support/guanyi-md`。本地体验包采用 ad-hoc 签名，未公证、未远端发布。
