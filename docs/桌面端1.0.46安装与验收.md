# 观译阅读器 1.0.46 安装与验收

验收日期 2026-11-25。目标平台为 Apple Silicon Mac。桌面端从应用包读取与 Web 同源的 `index.html`。新版保留桌面主进程、文件关联和原生工作区能力。

## 安装到同一位置

1. 保存正在编辑的文件，按 `⌘Q` 完全退出观译阅读器。
2. 打开 [1.0.46 归档 DMG](../release/archive/1.0.46/Guanyi-Reader-1.0.46-mac-arm64.dmg)，把 `观译阅读器.app` 拖到镜像里的「应用程序」。系统询问时选择「替换」。
3. 从「应用程序」启动，在关于界面确认版本为 `1.0.46`。推出磁盘映像。

版本号只写在 DMG 文件名和应用版本信息里。应用始终安装到 `/Applications/观译阅读器.app`，应用标识为 `com.guanyi.md`，资料目录为 `~/Library/Application Support/guanyi-md`。后续版本继续使用这三项固定身份。选择 Finder 的「保留两者」或把应用拖到其他目录，会额外留一份应用。
