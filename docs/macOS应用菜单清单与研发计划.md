# 观绎 MD macOS 应用菜单清单与研发计划

## 1. 目标与原则

macOS 顶部菜单固定为 5 个一级菜单：`观绎 MD`、`文件`、`编辑`、`查看`、`帮助`。

- “格式”并入“编辑 > Markdown 格式”，减少一级菜单数量。
- “窗口”并入“查看”末组，保留 macOS 标准最小化与缩放窗口行为。
- “关于观绎 MD”保留在应用名菜单首项，符合 macOS 惯例。
- 文档、历史、搜索、格式和视图命令调用编辑器已有函数，不模拟点击工具栏。
- 剪切、复制、粘贴、缩放、全屏等系统行为继续使用 Electron 原生角色。
- TXT 中 Markdown 格式菜单整体禁用；查找、保存、导出与视图仍可使用。

## 2. 五个一级菜单

### 2.1 观绎 MD

| 菜单项 | 快捷键 | 行为 |
| --- | --- | --- |
| 关于观绎 MD | - | 原生关于面板，显示真实版本、Logo、Slogan 与本地优先简介 |
| 设置… | `Cmd+,` | 打开现有“AI 阅读与问作品模型”配置面板 |
| 服务 | 系统 | macOS Services |
| 隐藏 / 隐藏其他 / 全部显示 | 系统 | macOS 标准窗口管理 |
| 退出观绎 MD | `Cmd+Q` | 退出前沿用现有搜索服务清理流程 |

### 2.2 文件

| 菜单项 | 快捷键 | 行为 |
| --- | --- | --- |
| 新建文档 | `Cmd+N` | 复用 `createDoc`，桌面端立即写入默认本地文档目录 |
| 打开文档… | `Cmd+O` | 打开 `.md/.markdown/.txt` |
| 添加目录… | - | 打开现有目录管理面板 |
| 刷新已添加目录 | - | 精确同步目录增删改与索引变更 |
| 打开文件位置 | - | 仅当前文档有真实磁盘路径时启用 |
| 保存 | `Cmd+S` | 复用冲突保护、原位保存与首次保存流程 |
| 导出 > Markdown / TXT 原文、PDF、PNG 长图 | - | 复用现有三种导出函数 |
| 关闭窗口 | `Cmd+W` | macOS 标准行为 |

### 2.3 编辑

| 分组 | 菜单项 | 快捷键与说明 |
| --- | --- | --- |
| 历史 | 撤销、重做 | `Cmd+Z` / `Shift+Cmd+Z`；接编辑器 50 步历史，不使用 Electron 原生撤销 |
| 剪贴板 | 剪切、复制、粘贴、全选 | 服从当前焦点的系统角色 |
| 查找 | 查找当前文档、查找与替换、搜索文档库 | `Cmd+F`、`Option+Cmd+F`、`Shift+Cmd+F` |
| Markdown 格式 | 粗体、斜体、删除线、链接、行内代码、无序列表、有序列表、任务列表、引用、代码块、分割线 | 复用 `formatFromActiveEditor`，三视图一致 |

`Cmd+H` 始终保留给 macOS“隐藏应用”，不再作为替换快捷键。Windows / Linux 仍使用 `Ctrl+H`。

### 2.4 查看

| 分组 | 菜单项 | 行为 |
| --- | --- | --- |
| 视图 | 源码、预览、分栏 | radio 状态与顶部视图控件双向同步 |
| 主题 | 亮色、暗色 | radio 状态与主题按钮双向同步 |
| 页面 | 实际大小、放大、缩小、切换全屏 | Electron 标准行为 |
| 窗口 | 最小化、缩放窗口 | 从原“窗口”一级菜单并入 |

### 2.5 帮助

| 菜单项 | 行为 |
| --- | --- |
| 观绎 MD 使用指南 | 打开随包离线帮助窗口，不创建用户文档 |
| Markdown 快速参考 | 展示支持的语法、列表与图片行为 |
| 键盘快捷键 | 展示与实际 accelerator 一致的快捷键 |
| 本地搜索与索引 | 说明关键词、语义、原文回答、索引时机与降级 |
| 数据与隐私 | 说明本地数据、索引、模型请求和 API Key 边界 |
| 打开诊断日志文件夹 | 打开搜索服务日志目录，不复制正文、问题或 API Key |

## 3. 命令与安全架构

1. 主进程的 `desktop/application-menu.cjs` 是菜单结构和命令白名单的唯一来源。
2. 自定义菜单通过 `guanyi:command` 只发送白名单命令 ID。
3. preload 再做一次白名单校验，不向页面暴露任意 IPC 或 Node.js 能力。
4. renderer 复用现有业务函数执行命令，并通过 `guanyi-menu:state` 上报清洗后的布尔状态、视图和主题。
5. 状态快照不包含文档正文、文件路径、搜索词、API Key 或模型配置。

## 4. 不纳入当前菜单的能力

1. **检查更新**：签名、公证、稳定更新地址、失败回滚完成前不放置虚假入口。
2. **开发者工具**：正式菜单不面向普通用户暴露。
3. **复制 UID、套餐、额度**：账户与商业化体系尚未确认，不照搬其他产品。
4. **云同步**：登录/我的仍处于原型确认阶段，本地编辑不依赖登录。

## 5. 验收标准

- [ ] macOS 菜单栏严格为 5 个一级菜单，顺序正确。
- [ ] 格式和窗口均已归入正确二级位置，没有重复入口。
- [ ] 新建、打开、保存、导出、查找、搜索、格式与视图和工具栏行为一致。
- [ ] 撤销/重做使用同一份 50 步编辑器历史。
- [ ] `Cmd+H` 隐藏应用，`Option+Cmd+F` 打开替换。
- [ ] 无文档、无磁盘路径、无目录、不可撤销/重做时禁用态准确。
- [ ] TXT 禁用 Markdown 格式，但纯文本编辑、查找、保存和导出正常。
- [ ] 打开和关闭离线帮助不改变当前文档、焦点、选区、历史或脏状态。
- [ ] 关于面板显示当前 `package.json` 版本。
