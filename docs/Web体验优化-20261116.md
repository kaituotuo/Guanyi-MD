## 用户可见变化

1. 主页和 AI 对话使用圆角输入框，按内容自动增高；Enter 发送、Shift+Enter 换行，中文输入法确认不会误发送。发送与停止在同一位置显示，保留生成期间新输入的草稿。
2. 对话正文收窄居中；用户消息右侧气泡，AI 回答直接排版，支持段落、列表、代码等 Markdown。去除重复角色及自由对话说明，来源详情按需展开，保留复制回答与整理为 Markdown。
3. 进入对话后左栏切换为对话列表，可新建或切换历史；回主页恢复文件列表。窄屏用可关闭抽屉，关闭后焦点归还。
4. 顶栏独立模型下拉移入“…”→“切换模型”，通过二级单选菜单切换。CC Switch 当前 Codex 与 Claude 连接分别列出，持久化所选来源，每次请求重新读取对应连接；选中来源失效不回退到其他来源或旧连接。
5. 可关闭弹框统一提供右上角 SVG 关闭图标，补齐图片裁剪、表格尺寸、关闭页签确认、PDF 页段、学习卡及整理弹框；保留取消、Esc、焦点恢复及保存失败输入。
6. 页面品牌与标签图标统一使用已安装客户端 1.0.45 的竹简资产。已核对安装包内 SVG 和 icon-512.png 与仓库文件字节一致，品牌文案保持“俯仰观物，译述我心”。

## 模型读取约定

- CC 的列表接口只返回可展示元数据；Web API Key 保持在本机服务内存，按请求快照与来源绑定。
- Claude 未显式配置完整模型时，先考虑启用的公共模型配置；仅在地址、凭据和鉴权类型均与当前供应商匹配时，采用本机 Claude 当前模型设置。
- `opus` / `sonnet` / `haiku` 别名优先采用显式 DEFAULT 模型设置，否则读取已安装 Claude CLI 内置目录的真实默认映射；不按版本号猜选。无法解析时明确提示配置完整模型标识。
- 本轮读取真实模型目录核对 ID；自动化对话采用隔离测试模型，未用用户文档验收云模型回答质量。

## 会话管理与返回入口补充

按用户补充，侧栏每条对话都支持右键菜单或行末“…”→“删除对话”。删除采用可恢复方式，从活动列表移除，保留消息、来源和未发送草稿。全局“…”→“历史对话记录”提供“全部 / 已删除”筛选、只读详情和“恢复对话”；恢复后可以重新打开并继续。

顶部新增常驻“AI 对话”页签。从 Markdown/TXT 编辑或 PDF/EPUB 阅读返回时，恢复原活动对话和草稿。历史弹框可以覆盖任意工作区，查看或 X/Esc 关闭不切换底层文档，关闭后归还焦点；从历史主动“回到原文”成功后关闭弹框，便于查看定位结果。键盘 Enter/Space 激活主页或 AI 对话页签后焦点保留。窄屏品牌区保持完整宽度，页签区使用剩余宽度并支持横向滚动，多文档时不再挤压品牌。

删除正在生成的会话会取消当前请求并等待结束，晚到结果不写入其他对话。删除或恢复保存失败时回滚，不把保存失败展示为成功。删除最后一条后保留空对话界面，用户输入时再创建会话。
