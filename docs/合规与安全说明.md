# 观译阅读器 1.0.38：数据、第三方许可与签名说明

更新日期：2026-11-09。适用范围：本仓库 1.0.38 源码及本次 macOS Apple Silicon 体验安装包。本文记录已实现的数据处理方式和发布边界，不是第三方安全审计、法律合规认证或“无漏洞”证明。本次不发布 Windows 1.0.38 安装包。

## 本地数据与升级

本版将产品显示名称改为“观译阅读器”，沿用 `com.guanyi.md` 应用标识与 `guanyi-md` 用户数据目录，以保留旧版文档、目录、偏好和搜索索引。

macOS 默认数据位置如下：

| 数据 | 位置或处理方式 |
| --- | --- |
| 文档内容、目录绝对路径、当前页签、阅读位置及 EPUB 标注 | `~/Library/Application Support/guanyi-md/state/editor-state-v1.json`；渲染器同时使用本地存储 |
| 应用托管的 Markdown 文档及相关图片 | `~/Library/Application Support/guanyi-md/documents/` |
| PDF / EPUB 原文件副本、PDF 批注草稿 | `~/Library/Application Support/guanyi-md/binary-documents/` |
| 本地搜索数据库、元数据及诊断日志 | `~/Library/Application Support/guanyi-md/search/meilisearch-v4/` |
| 浏览器版阅读文件 | 当前站点的 IndexedDB；文档状态与设置使用当前站点的本地存储 |

文档与缓存没有额外的应用级加密；磁盘与账户保护取决于操作系统设置。列表中的“移除文档/目录”不删除用户磁盘原件，也不等于彻底清除所有应用缓存。本版没有完整缓存清理或安全擦除功能。备份阅读批注时，应同时保留应用数据，或使用“另存 PDF / 导出笔记”生成可独立保存的文件。

应用未实现自建云端账户或文档云同步。用户将文件放在 iCloud、网盘同步目录，或主动发送给第三方服务时，相应数据处理由这些服务决定；本文不承诺这些外部系统的保存或删除行为。

实现依据：`desktop/main.cjs`、`desktop/binary-documents.cjs`、`js/reader-host.js` 与 `js/app.js`。

## 文件打开、修改与保存

- Markdown / TXT 单份打开限制为 20 MB；PDF / EPUB 单份打开及二进制缓存限制为 100 MB，并检查基本格式签名。目录扫描只包含 Markdown / TXT，最多扫描 5 层。
- Markdown / TXT 的“保存”可写回已关联文件；“另存为/移动”采用对应文件工作流。PDF 阅读批注先保留在应用草稿中，通过“另存为”导出含批注的 PDF。默认建议新文件名；若用户在系统对话框中选中原路径并确认替换，该目标仍会被覆盖。
- EPUB 首版保留原书字节，高亮、批注与笔记存入应用状态，可导出 Markdown 阅读笔记，不把笔记回写成修改后的 EPUB 正文。
- 原生二进制保存先写同目录临时文件并同步，再替换目标。批注写入失败时保留仍可重试的阅读实例；正常关闭窗口或退出应用会等待批注与状态落盘，失败时返回文档。强制结束进程、断电或磁盘损坏仍可能导致最近修改丢失。
- PDF / EPUB 不能进入 Markdown 的 UTF-8 写入、重命名或移动事务，避免把二进制原件误写成文本。

实现依据：`desktop/binary-documents.cjs`、`desktop/main.cjs`、`js/reader-host.js` 与 `js/app.js`。这些限制是当前版本的边界，不构成对任意损坏或恶意文件均可安全处理的保证。

## PDF / EPUB 内容处理

PDF 使用固定版本的 Mozilla PDF.js 官方完整阅读器。集成层关闭 PDF 脚本执行与动态求值、关闭文档内外部链接跳转，并将下载动作交回应用的另存流程；PDF 附件不在应用内直接打开。阅读器保留 PDF 权限处理。PDF.js 自身使用的脚本和本地 worker 仍是阅读功能所需的应用代码，不应把“关闭 PDF 文档脚本”理解成浏览器完全不执行 JavaScript。

EPUB 使用 epub.js 和 JSZip。渲染前移除书内脚本、表单、嵌套框架与事件属性；书页采用禁止脚本、网络连接及外部资源的内容安全策略，只允许适配器提供的 `blob:` / `data:` 资源，并禁用弹窗与外部链接。检查 ZIP 资源数量及声明的解压大小：最多 10,000 个文件，总声明大小不超过 200 MB，单项不超过 40 MB。这是资源消耗保护，不能等同于对所有畸形压缩文件的完整安全证明。

本版不提供 DRM 移除或绕过功能。EPUB 发现不支持的加密方式时拒绝打开；标准字体混淆标识与 DRM 加密区分处理。请仅打开、摘录、导出和分享有权使用的内容。PDF 密码或权限限制由阅读器处理，不提供破解能力。

本版没有 OCR。扫描 PDF 能否选择、搜索和高亮文字取决于原文件是否包含文字层；阅读批注也不等于改写 PDF 排版或 EPUB 正文。

实现依据：`js/pdf-reader.js`、`js/epub-reader.js`，以及 `vendor/pdfjs/README.guanyi.md`。

## 联网与 AI 数据范围

普通本地阅读、文件编辑和批注不需要调用远程大模型。本地语义搜索使用随包提供的模型与 Meilisearch，索引服务绑定 `127.0.0.1`、使用本机访问密钥并关闭其分析遥测；本地模型运行配置禁止远程模型下载。PDF / EPUB 首版不加入 Markdown / TXT 全库正文检索或“问作品”范围。

用户主动配置模型并触发 AI 操作时，应用会向其填写的模型服务地址发送请求。不同功能的数据范围有区别：

| 操作 | 发给所配置模型服务的数据 |
| --- | --- |
| 测试连接或读取模型列表 | 模型服务地址、认证信息及测试/模型列表请求 |
| 生成 AI 辅助阅读 | 当前 Markdown / TXT 文档的完整内容及分析指令；不是只发送摘录 |
| 问作品的问题规划 | 用户问题、当前阅读上下文及有限文档标题/类型清单；规划清单使用临时编号，不发送目录绝对路径 |
| 问作品、原文回答的整理 | 用户问题、当前上下文、召回的有限原文证据，以及作品标题与章节信息 |

API Key 通过认证请求头发送给用户配置的服务。默认放在当前会话存储；勾选“记住”后保存在应用的本地存储中，当前未接入 macOS Keychain。清除模型配置会移除应用保存的配置和密钥，但无法撤回此前已发给服务商的请求。

桌面模型通道校验调用来源、请求编号和 URL 协议，并提供取消、超时及体积上限：请求正文 1 MB、响应 2 MB，单次超时最多 120 秒。当前支持用户配置的 HTTP 或 HTTPS 地址；HTTP 本身不提供传输加密，应使用可信 HTTPS 服务或受控的本机服务。服务商是否保留请求、用于训练或跨境处理，取决于用户选择的服务及其条款，本应用不作代为保证。

用户主动点击应用中的帮助、更新等外部入口，或在 Markdown 中使用远程图片，也可能产生网络访问；“本地优先”不表示整个应用永不联网。

实现依据：`desktop/ai-transport.cjs`、`desktop/meilisearch-process.cjs`、`desktop/semantic-search.cjs` 及 `js/app.js` 中的 `requestModel`、`generateAiReading`、`generateOriginalAnswer` 和 `planWorkRetrieval`。

## macOS 签名、证书与公证

1.0.38 Mac 体验包采用 ad-hoc 本地签名，未使用 Apple Developer ID Application 证书，未完成 Apple 公证，也未通过 Mac App Store 审核。Windows 1.0.38 本次不发布；不能将旧 Windows 包的签名状态当作本版认证。

ad-hoc 签名可用于本地代码完整性校验，但没有 Developer ID 所提供的开发者身份信任链。`codesign --verify` 通过、DMG 可挂载或 SHA-256 一致，都不等于取得 Apple 公证、App Store 审核或安全认证。

Apple 说明，面向 Mac App Store 之外的分发可以使用 Developer ID 签名并提交公证，供 Gatekeeper 核验；公证是恶意内容及签名问题的自动检查，不是 App Review。[Developer ID 证书](https://developer.apple.com/help/account/certificates/create-developer-id-certificates)、[Apple 公证说明](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)。

因此，系统可能对本体验包显示未识别开发者或无法检查恶意软件的提示。只有确认下载来源和发布页校验值后，才应按系统提供的正常流程决定是否打开；本项目不要求关闭整机 Gatekeeper 或降低全局安全设置。系统处理说明见 [Apple：安全打开 Mac App](https://support.apple.com/en-us/102445)。

未来如提供 Developer ID 签名及公证版本，应在对应发布页列出实际证书身份、公证结果和产物校验值。在这些流程实际完成之前，不标注“已公证”“Apple 认证”或类似承诺。
