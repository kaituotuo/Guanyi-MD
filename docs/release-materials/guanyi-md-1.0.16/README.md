# 观绎 MD 1.0.16 发布素材

本目录用于整理观绎 MD 1.0.16 的发布截图、品牌素材和功能说明文案，便于 README、产品介绍、更新说明和社交媒体发布时复用。

## 目录结构

- `feature-copy.md`：新版本功能说明，可直接改写为 README、更新日志或发布文案。
- `assets-manifest.md`：图片清单、来源、用途和状态说明。
- `screenshots/`：经过整理的截图素材。

## 素材使用约定

- `semantic-search-failure-repro.png` 是历史问题复现截图，记录语义搜索服务启动失败的状态；`semantic-search-failure-partial-index.png` 记录搜索完成但部分目录未连接/授权的状态。两者仅用于问题修复说明或回归对比，不应作为新版本成功效果图。
- `wps-image-editing-reference.png` 是交互参考图，来自金山文档体验，不代表观绎 MD 的功能截图。
- 其余截图为观绎 MD 界面素材，发布前请根据最终安装包再次确认截图与实际功能一致。
- 图片均为发布素材副本；原始截图仍保留在系统临时目录或项目资源目录中，本目录不存放视频文件。

## 发布前检查

1. 将语义搜索成功结果截图补充到 `screenshots/`，并在 `assets-manifest.md` 中登记。
2. 确认版本号、安装包名称和截图中的界面版本一致。
3. 对外发布前移除仅供研发使用的失败复现图，或在正文中明确标注其历史问题属性。
