# 观绎 MD 1.0.16 功能说明

## 一句话介绍

观绎 MD 是一款以书写者为中心的本地 Markdown 编辑器：向外观万物，向内绎本心。它把源码编辑、所见预览、本地文档管理和可选的本地语义检索放在同一套工作流中。

## 本版本重点

### 更完整的 Markdown 编辑体验

- 支持源码、预览和分栏三种视图，分栏状态下可拖动中线调整左右视窗比例，并保持最小、最大宽度约束。
- 提供标题、粗体、斜体、引用、分割线、无序列表、有序列表和任务列表等常用编辑能力。
- 列表回车会沿用当前列表规则；列表、任务列表、普通段落和图片之间可以连续穿插编辑。
- 支持撤销和恢复、查找与替换，并对无结果状态提供明确反馈。

### 图片插入与二次编辑

- 支持 PNG、JPEG/JPG、GIF、WebP 等常见本地图片格式。
- 图片可在同一行排列 1 到 6 张，并采用等高布局；拖动图片到相邻行时会按目标行容量重新编排。
- 选中图片后提供缩放、左对齐/居中/右对齐、添加描述、裁剪和下载等操作。
- 源码视图中的图片采用紧凑的单行占位表达，避免长编码遮挡正文，同时保留光标定位和继续编辑能力。

### 本地文档管理

- 支持打开和管理 Markdown、TXT 文档，也支持添加本地文件夹并扫描其中的文档。
- 文件夹目录默认扫描 5 层，可手动刷新已添加目录，及时发现新增或更新的文件。
- TXT 单文件大小上限为 20 MB；长文本在预览视图中按视窗宽度自动换行，便于阅读。
- 桌面版升级时保留已添加的目录、文档列表和本地配置，不要求用户重复授权。文档内容仍以用户本地文件为准。

### 统一搜索

搜索入口统一处理文件名、文件夹名、正文关键词和语义相近内容，用户无需先选择搜索模式。搜索结果支持点击定位到对应文档和内容，并对匹配关键词进行醒目高亮。

这也是观绎 MD 与常见主流工具的关键差异：在本地 Markdown、TXT 和长篇文档的常规内置搜索场景中，WPS、Microsoft Office、飞书文档，以及 macOS 系统自带的预览、图书等阅读器，都不支持观绎 MD 这种从句子一路检索到段落、小节和章节的本地语义搜索；它们通常只能“输入原词，匹配原词”。观绎 MD 还能理解你想找的意思：不必记得原文的准确措辞，输入“火烧博望坡”“谁打了黄盖”或“袭人的名字来历”，也能从本地长篇文档中找到语义相关的内容。

语义检索在本地使用 `bge-small-zh-v1.5` 生成文本向量，结合 Meilisearch 建立和查询索引。文本会按句子、段落、多段、小节和章节等粒度切分，适配有规范标题的 Markdown，也兼容没有明确章节标题的长文章。模型、索引和文档内容均在本机运行，不上传到云端。

当文档内容或分块规则发生变化时，系统会增量更新索引；升级后只有无法复用的旧索引需要重建，未变化的文档可继续使用已有索引。

## 设计取向

观绎 MD 的视觉和交互以“俯仰观物，绎述我心”为线索，保留古典哲思的克制气质，同时优先保证编辑效率：工具栏图标采用更清晰的拼色和较稳的视觉重量，状态反馈靠明确的选中、悬停和结果高亮传达，而不是依赖难以理解的装饰点。

## 对外发布短文案

观绎 MD 1.0.16，继续把 Markdown 写作留在本地。现在可以在源码、预览和分栏视图之间切换，连续处理列表、任务、图片和长文本；图片支持 1–6 张等高排列、缩放、对齐、描述、裁剪和下载。WPS、Office、飞书和 macOS 系统阅读器的本地常规搜索都不支持这种句子到章节的语义检索，观绎 MD 把它放在编辑器里：不必记住原句，也能找到真正相关的内容，并直接定位、高亮。添加的目录、文档和可复用索引随桌面版升级保留，写作从打开文件开始，也从本地完成。

## 关于观绎

“观”取《周易·系辞上》“仰以观于天文，俯以察于地理”；“绎”取《论语·子罕》“绎之为贵”。观，是向外保持好奇与敏锐；绎，是把观察所得抽丝理绪，沉淀为自己的文字。观绎 MD 不以工具束缚人，而为人承载思想。
