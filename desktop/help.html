观译阅读器使用指南

支持 Markdown、TXT、PDF 和 EPUB 的本地阅读与批注工具。打开本地文档无需登录。

开始一份文档

  1. 使用“文件 > 新建文档”创建 Markdown 文档，或“打开文档”载入 Markdown、TXT、PDF 和 EPUB。
  2. 使用“添加目录”将 Markdown / TXT 文库加入左侧文档列表；手动刷新会同步磁盘新增、修改、移动和删除。
  3. Markdown 可在源码、预览和分栏视图间阅读、编辑。TXT 保留原文和换行；PDF 与 EPUB 会显示各自的阅读、批注工具栏。
移除文档或目录只会移出观译阅读器的列表，不会删除磁盘上的真实文件。

PDF 与 EPUB 阅读

打开 PDF 或 EPUB 后，顶部工具栏会切换为对应的阅读工具，图标风格与 Markdown 保持一致。

  • PDF：翻页、缩放、查找，选择原文添加高亮、批注和笔记。批注草稿保存在本机，“另存为”可导出含批注的 PDF。
  • EPUB：使用章节目录、翻页和字号设置阅读；选择原文添加高亮与笔记。阅读位置和标注保存在本机，“导出笔记”可生成 Markdown 摘录与笔记文件。
  • Markdown 与 TXT 可编辑正文。PDF 与 EPUB 的编辑范围为高亮、批注和笔记。

列表回车会延续当前规则；空列表再次回车会退出列表。TXT 文档不会启用 Markdown 格式命令。

本地搜索与索引

文档库搜索针对已添加的 Markdown 与 TXT 文档，同时进行文件名、目录名、正文关键词与本地语义召回，结果可定位到原文位置。默认范围是已添加的文本文档，也可切换为当前文档。

索引更新

添加目录、打开文档、文档保存或手动刷新目录后，变更内容会进入增量索引。语义服务暂不可用时，关键词搜索仍可继续使用。

原文回答与问作品

答案必须以实际召回的原文为证据；未找到足够证据时会明确降级，不会伪造出处。

数据与隐私

  • 文档正文、已添加目录和本地语义索引默认保存在本机。
  • 关键词与本地语义搜索不要求把文库上传到云端。
  • 只有主动使用 AI 辅助阅读或问作品，并完成模型配置后，相关输入才会发送到所选模型服务。
  • API Key 不写入诊断信息；帮助窗口也不会读取当前文档、搜索问题或本地路径。
